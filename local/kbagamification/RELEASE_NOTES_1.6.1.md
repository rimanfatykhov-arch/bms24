# KBA Gamification 1.6.1 — Navigation UX

This release fixes discoverability of learner-facing KBA Gamification pages.

Learners now get a standard **KBA Profile** navigation entry and a consistent in-page menu: **My profile · Achievements · Leaderboard · Rewards · My orders**, subject to capabilities and enabled features.

No database schema changes are introduced. Existing XP, Coins, levels, achievements, transactions, rewards and orders are preserved.

Requires: Moodle 4.0+ (`2022041900`)
