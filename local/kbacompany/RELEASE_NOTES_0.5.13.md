# Release notes — BMS v0.5.13

**Build:** 2026091511  
**Тема:** Готовность управленческой недели

- Добавлен read-only экран `battle_plan_readiness.php`.
- По каждому плану показывается readiness к следующему lifecycle-переходу.
- Жёсткие блокеры повторяют существующие правила: проверяющий + минимум одна задача перед отправкой черновика.
- Самопроверка корректно выделяется как `ready_selfapprove`.
- `submitted` с корректным проверяющим отображается как `ready_activate`.
- Пробелы критических показателей и действующих норм показываются как advisories и не меняют state machine.
- Observer остаётся опциональным.
- Добавлены сводки готовности по подразделениям и фильтры по неделе/подразделению/readiness.
- Схема БД, capabilities, external services и privacy schema не меняются.
