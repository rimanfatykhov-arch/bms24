# local_kbacompany 1.1.0-rc18 — Management Cycle 2.0

Build: `2026101238`

## Scope

This release presents the regular BMS24 management cadence as one explainable five-function contour:

**Planning → Organization → Leadership → Control → Correction**

for canonical **Week / Month / Quarter / Year** Management Cycles.

### Current cadence
- The Management Cycles list now shows the current Year → Quarter → Month → Week hierarchy for today's date.
- Missing levels can be created from their existing canonical templates.
- No hierarchy record or second cycle engine is introduced.

### Five-function workspace
- Every regular cycle overview shows five derived management stages.
- Planning reads the cycle priority, outcome, accountability and linked Metrics.
- Organization reads canonical checkpoints and Battle Plans.
- Leadership reads canonical tasks, meetings and accepted decisions.
- Control reads checkpoint completion/overdue state and Metric fact availability.
- Correction reads canonical A3 reviews, open execution and explicit next-period rollover.

### Closure attention
- The overview reports explicit attention signals before closure: overdue checkpoints, open A3 work and unfinished tasks without a next-period cycle.
- This is advisory. It does not silently close tasks, create facts, alter meetings or replace the cycle owner's decision.
- No hidden percentage score is used.

## Compatibility
- No DB schema changes.
- No capability changes.
- No privacy storage changes.
- Project and advisory templates continue to use their existing cycle UI; the five-function projection is intentionally limited to Week / Month / Quarter / Year.
