# Приёмка BMS24 RC29 · build2026101631

## До установки

1. Создать резервную копию БД Moodle и каталога `local/kbacompany`.
2. Убедиться, что текущая версия — `build2026101630`, либо зафиксировать фактический номер для контроля обновления.
3. Установить архив, пройти обновление Moodle, очистить кэши сайта и перезагрузить страницу (Ctrl+F5).
4. Проверить наличие поля `changedby` в `local_kbacompany_taskrec` и успешную миграцию `2026101631`.

## Функциональные сценарии

- [ ] Открыть существующую регулярную серию с несколькими ревизиями: увидеть журнал с датой, временем и версиями.
- [ ] Проверить исторические записи: для ревизии №1 отображается создатель, для ревизий №2+ до этого релиза неизвестный автор отмечен «Автор не установлен».
- [ ] Изменить ожидаемый продукт от лица редактора и сохранить: появляется новая ревизия с правильным действующим пользователем и конкретным изменением продукта.
- [ ] Изменить периодичность / исполнителя: история корректно показывает до/после, без переписывания уже созданных задач.
- [ ] Активировать / приостановить тестовую серию: появляется ревизия с изменением статуса и реальным автором.
- [ ] Нажать «Задачи по этой версии»: в журнале только фактически созданные экземпляры с соответствующим `sourcerevision`. «Показать все задачи» снимает фильтр.
- [ ] Переключить страницы истории и журнала; GET-параметры не обходят права доступа.
- [ ] Проверить старые серии, где описание содержит SHA256 исходного библиотечного шаблона: в истории SHA256 не раскрывается.
- [ ] Войти сотрудником без прав управления чужой серией: убедиться, что не раскрываются недоступные серии.
- [ ] Войти в другую компанию с чужим UUID серии: история и журнал не отображаются.
- [ ] Открыть карточку на узком экране: нет горизонтального переполнения и перекрытия кнопок.
- [ ] Проверить, что cron создает экземпляры по текущей активной версии и не создает дубликатов при повторном запуске.

## Критерии допуска

Релиз можно считать принятым после успешной миграции БД и прохождения функциональных сценариев на вашем Moodle. Локальные проверки исходников не заменяют этой приёмки.
