# BMS24 RC29 build2026101629 — Журнал экземпляров регулярной серии

Дата 16.10.2026. Базовая сборка `build2026101628`.

## Что реализовано
- В DetailView регулярной задачи добавлен блок «Созданные задачи по расписанию» под предварительным просмотром ближайших выполнений.
- Журнал читает существующий канонический реестр `local_kbacompany_task` по `companyuuid`, `sourcekind=recurring`, `sourceuuid=серия`; не создаёт задач и не меняет их статус.
- Каждая строка показывает дату из `periodkey`, ссылку на задачу BMS, исполнителя, фактический статус, закреплённую при генерации версию (`sourcerevision`) и срок (`duedate`, если отличается).
- К задаче привязываются только уже существующие записи `local_kbacompany_bplanitem` с `provider=bms`, ссылающиеся на реальный `local_kbacompany_bplan`. Показывается период соответствующего плана со ссылкой. Если план отсутствует либо недоступен текущему пользователю, показывается «Не включена в доступный план».
- Пагинация по 20 **видимых** задач: сначала отдельная проверка Task Center ACL для каждого экземпляра, затем отбор страницы; связи с планами независимо проверяются через канонический `battle_plan_service::context()`. Граница компании проверяется во всех выборках. Чужие задачи/планы, даже при угадывании UUID, не раскрываются.
- Адаптивная прокрутка широкой таблицы на мобильных экранах. Отдельные русские и английские переводы без технических ключей.

## Что сознательно не делали
Не добавлены таблицы/DDL, не менялись генератор cron и периодичности, правила idempotency, права на добавление в боевой план, существующие экземпляры, идентификаторы и ревизии. Не включён автоматический перенос задач в уже согласованные планы: существующая синхронизация по-прежнему разрешена только для черновиков.
