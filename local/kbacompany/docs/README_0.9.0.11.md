# local_kbacompany 0.9.0.11 build2026092507
## Справочник должностей — BMS UI / CRUD

Полный ALPHA-пакет на основе точного INSTALL 0.9.0.10 build2026092506.
Раздел positions.php: отдельные список, карточка, создание и редактирование.
Существующая нормативная должность не заменяется штатной единицей или сотрудником.

### Установка

Сохранить согласованную резервную копию БД, moodledata и кода. Сначала проверить
на тестовой копии Moodle 4.1.22. Установить только INSTALL_ME ZIP как обновление
существующего local_kbacompany, затем завершить штатное обновление Moodle через
«Администрирование сайта → Уведомления» и очистить кэши.

Не удалять плагин через Moodle и не сбрасывать установленный номер версии.
Новых изменений схемы относительно 0.9.0.10 нет. Файлы install.xml, upgrade.php,
upgradelib.php и восстановление norm_ix сохранены побайтно. При обновлении с более
ранней версии необходимо завершить все унаследованные миграции; очистка кэшей
их не заменяет. Не запускать параллельно web/CLI обновления.

При ручном размещении скопировать содержимое kbacompany/ в local/kbacompany/;
не создавать вложение local/kbacompany/kbacompany.

### Рабочий путь

Люди → Должности и роли → Справочник должностей → имя должности → карточка.
Кнопка «Создать должность» открывает отдельную форму. После сохранения открывается
карточка. «Редактировать» меняет название, назначение, признак руководящей работы
и порядок отображения. Действия ведут к существующим профилю компетенций,
должностной папке, штатному расписанию и штатной расстановке.

Карточка: Обзор / Функции и результаты / Штат / История изменений.
Новый код POS-xxxx присваивается автоматически существующим счётчиком компании;
старые коды сохраняются, коды не редактируются. Подразделение выбирается явно
при создании; перенос существующей должности здесь не реализован.

### Границы

Изменение определения не меняет штатное расписание, назначения сотрудников,
компетенции, роли доступа, документы, задачи или обучение. Признак руководящей
должности не назначает пользователю управленческие права.

Функции показываются из канонического реестра с видимостью опубликованных редакций
для читателя. Штат — строки утверждённых расписаний с их периодами; разные планы
не суммируются и не объявляются автоматически текущими. Нет строки — не значит вакансия.

История показывает до 50 новых метаданных событий этого UI из подключённого
SQL-совместимого журнала Moodle: кто, когда, действие и названия изменённых полей.
Значения до/после и восстановление старых редакций не добавлялись. Старые изменения
задним числом не создаются, хранение зависит от настройки журнала Moodle.
Перенос, удаление, архивирование/реактивация и версии должностей не включены.
