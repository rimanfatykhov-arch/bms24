# BMS24 0.9.0.1 — Меню и навигация

Компонент: `local_kbacompany`. Сборка: `2026092413`. База: `0.9.0 build 2026092412`.
Статус: ALPHA, установочный пакет; установка на сервер не выполнялась.
Целевая платформа проекта: Moodle 4.1.22, PHP 7.3+. Минимальный `requires`
из базового пакета не менялся. PHP 7.3 runtime не запускался.

## Какой ZIP устанавливать

`INSTALL_ME_local_kbacompany_v0.9.0.1_build2026092413.zip` — полное обновление плагина.
SOURCE и BMS_RELEASE_KIT предназначены для разработки и аудита; Release Kit не устанавливается в Moodle.

До обновления сохраните резервную копию кода, БД и moodledata. Обновите существующий
local/kbacompany полным INSTALL-пакетом и выполните штатное обновление Moodle.
Очистите кэши Moodle и перезагрузите страницу. Для 0.9.0 → 0.9.0.1 схема БД не меняется;
при переходе с более раннего выпуска выполняются существующие миграции 0.9.0.
Тему KBA переустанавливать этим выпуском не требуется: бизнес-меню принадлежит BMS.

## Видимые изменения

Вместо одной строки из 13 ссылок: Обзор / Планирование / Показатели / Решения / Рабочие места.
Вторая строка показывает только подразделы выбранной группы, не более четырёх.
На узком экране пункты переносятся без горизонтальной прокрутки и сокращения названий.
Все 13 прежних адресов сохранены для пользователей с соответствующими правами.

«Административная шкала» находится в «Архитектуре»; «Показатели» — в «Управлении».
В боковом меню отдельно доступны «Управленческие циклы» (периоды) и
«Исполнение и встречи» (прежний экран «Управленческий цикл»). Сущности не переименованы.
Короткие подписи «Документы» и «Отклонения» не изменяют содержание разделов.

На странице обзора оставлены две контекстные кнопки: исключения и управленческая неделя.
Остальные переходы доступны через меню «Решения». Исправлены ссылки `[[open]]` в цепочке управления.
Подробнее: RELEASE_NOTES_0.9.0.1.md и NAVIGATION_0.9.0.1.md.

Live Moodle, настоящая тема/браузер на сервере и production acceptance остаются NOT RUN.
Следующий функциональный этап roadmap — 0.9.1 Odoo adapter; этот UX-патч его не заменяет.
