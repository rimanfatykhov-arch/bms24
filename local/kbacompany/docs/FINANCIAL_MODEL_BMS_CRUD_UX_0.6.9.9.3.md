# FINANCIAL MODEL — BMS CRUD UX

Release: `0.6.9.9.3`\
Build: `2026092203`

## Цель

Привести текущий раздел «Финансовая модель» к `BMS-UX-CRUD-001`, сохранив существующий финансовый domain model и ownership boundaries.

## Рабочее пространство

Главная страница больше не является формой создания. Она показывает:

1. **Обзор** — состояние финансового контура и переходы к отчётности, бюджетированию и ресурсной проверке.
2. **Финансовые сценарии** — record-oriented реестр.
3. **Центры финансовой ответственности** — record-oriented реестр.

## Финансовый сценарий

Паттерн: `ListView → DetailView → EditView → Actions → History`.

DetailView показывает:

- Stable Code и название;
- тип сценария;
- период и валюту;
- статус/revision;
- закреплённые опубликованные Strategy и Business Model revisions;
- назначение и ключевые допущения;
- переходы к БДР/БДДС/балансу, бюджетированию и ресурсному шлюзу;
- историю редакций.

## Центр финансовой ответственности

ЦФО не является подразделением и не создаёт вторую оргструктуру.

ЦФО связывает:

- тип финансовой ответственности;
- существующую организационную область (Company / Org Unit / Position / Product);
- ответственную Position;
- существующий BMS Indicator;
- ожидаемый результат;
- правила полномочий/эскалации;
- частоту план-факт контроля.

## Stable Code

Новые записи используют существующий `stable_code_service`:

- Scenario: `FIN-0001...`
- Financial Responsibility Centre: `CFO-0001...`

UUID остаётся canonical identity. Legacy-коды сохраняются и не мигрируются принудительно.

## Не входит в релиз

- структурированный реестр финансовых допущений;
- экономическая проверка BMC TARGET;
- отдельный Financial Scenario validation engine;
- GAP Registry;
- новый KPI/Indicator engine;
- ERP Actual import.

Эти возможности должны строиться поверх данного CRUD, а не заменять существующие финансовые сервисы.
