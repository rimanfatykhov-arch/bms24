# BMS v0.5.1 — Информационный центр и история показателей

Информационный центр является read-model над каноническими `local_kbacompany_stat` / `local_kbacompany_statval` и версионными `statmeta/statbind/statnorm`. Он не создаёт отдельные копии показателей.

## Представления

- Организационный обзор: верхние подразделения ОФС → связанные показатели должностей/подразделений.
- Стратегический обзор: перспективы ССП → показатели связанных стратегических целей.
- Детальная карточка: 13/26/52 периодов, план/факт, норма, динамика и бизнес-контекст.

## Контроль нормы

Метка «В норме / Отклонение» отражает только соответствие текущего факта действующей норме с учётом направления показателя. Она не является формулой состояний НС/Опасность/ЧП/НД/Изобилие/Могучество. Полный движок состояний развивается отдельно.

## Данные

Новых таблиц в 0.5.1 нет. История остаётся append-only, нормы — versioned, связи — versioned.
