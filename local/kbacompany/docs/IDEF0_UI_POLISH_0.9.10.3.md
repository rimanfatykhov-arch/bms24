# IDEF0 UI Polish — 0.9.10.3

Presentation-only refinement of the existing IDEF0 workspace.

## Scope
- Context section gains compact I/C/O/M counts.
- Function node is visually dominant; ICOM areas/cards are denser and easier to scan.
- Decomposition help is compact text; child cards align notation and process name in one header.
- Interconnection cards render source and target as separate function nodes with notation badges.
- Balance status is separated into a short state label plus detailed explanation.
- Mobile layout keeps actions and status readable.

## Explicitly unchanged
- Process / Process Model / ICOM / Semantic Core data and services.
- Company scope, ACL, published immutability and draft semantics.
- Routes/controllers, schema, privacy, balancing rules and remediation behaviour.
- SIPOC/BPMN semantics.
