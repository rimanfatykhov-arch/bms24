### Установка

Сохранить согласованную резервную копию БД, moodledata и кода. Сначала проверить
на тестовой копии Moodle 4.1.22. Установить только INSTALL_ME ZIP как обновление
существующего local_kbacompany, затем завершить штатное обновление Moodle через
«Администрирование сайта → Уведомления» и очистить кэши.

Не удалять плагин через Moodle и не сбрасывать установленный номер версии.
По отношению к 0.9.0.9.2 новой миграции нет; при обновлении более старой версии
все ещё требуются ранее выпущенные миграции. Установленный 0.9.0.9.2 не является
обязательным промежуточным шагом: новый полный пакет содержит его исправление.
Незавершённое обновление БД нельзя заменить очисткой кэшей.

При ручном размещении скопировать содержимое kbacompany/ в local/kbacompany/;
не создавать вложение local/kbacompany/kbacompany. Дождаться завершения текущей
процедуры обновления, не запускать параллельные web/CLI upgrades.

### Рабочий путь

Люди → Сотрудники → имя сотрудника → карточка. Вкладки: Обзор, Организация,
История связи и, по правам управления организацией, Синхронизация.
Создание и редактирование открываются отдельно, после сохранения — карточка.
Исключение из компании выполняется отдельным подтверждённым действием.

Профиль Moodle общий для платформы. Изменения имени, email и телефона не являются
изолированной копией контактов одной компании. Должность/подразделение меняются
только в существующей штатной расстановке, а не в профиле.

Создание не отправляет нового приглашения и не зачисляет на курсы. Совпадение
email действующего сотрудника этой компании открывает его карточку без изменения
профиля/ролей. Нельзя этой формой автоматически присоединить существующую учётную
запись вне действующих canonical memberships этой компании: используйте согласованный
административный или интеграционный процесс. Новый реестр людей не создаётся.
