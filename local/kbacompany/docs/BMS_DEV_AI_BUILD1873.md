# BMS Dev AI — build2026101873

Техническая основа для отдельного управляемого контура AI-разработки.
Полный рабочий инструментарий находится **в исходном Git-проекте**, не в
устанавливаемом модуле Moodle.

- Schema task JSON, проверка области изменений, создание изолированного Git
  worktree и отдельные заключения QA / Security.
- Результат проверки — кандидат для **дальнейшей человеческой приёмки**,
  не разрешение на публикацию.
- Инструмент не использует внешние ИИ-модели, не обращается к производству,
  не выполняет SQL и не меняет схему БД.
- В Moodle-плагине обновлены только version/savepoint и этот документ с
  release notes. Бизнес-логика, маршруты, интерфейсы, роли и данные не меняются.

См. исходный репозиторий: `docs/AI_TASK_LIFECYCLE.md` и
`docs/features/STAGING_MOODLE_ACCEPTANCE.md`.
