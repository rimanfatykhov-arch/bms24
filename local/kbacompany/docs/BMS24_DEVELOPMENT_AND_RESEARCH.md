# BMS24 — Development / Product Research

## Development (выпуски)
- Основная ветка: RC29 → RC30. Текущая рабочая база: Moodle 4.1.22, PHP 8.1.34 (по данным пользователя).
- Минимальные проверки релиза: PHP lint, PHP 8.1 compatibility gate, Moodle XMLDB, последовательность upgrade, контроль источников, ZIP.
- Live acceptance обязательна для фактического подтверждения прав, действий CRUD, миграций, уведомлений и интеграций. Static QA не эквивалентен live-приёмке.
- Приоритет сценариев RC30: задача → недельный боевой план → перенос → протокол → подтверждение решения → групповое изменение → аудит.

## Product Research (исследования)
Для каждого нового материала фиксировать: источник, проблему пользователя, решение/референс, действующую реализацию BMS24, функциональный разрыв, целевой UI/CRUD, модель и права, риски, предлагаемую задачу и релиз-кандидат.
Категории: управление; люди; архитектура процессов; продажи; финансы; ИИ.
Статусы: Исследуется → Требования сформулированы → Утверждено → В разработке → Static QA → Live PASS → Выпущено.
