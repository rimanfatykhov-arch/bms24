# RC30: автономное сравнение отчётов (build2026101871)

## Для чего

Новая команда `cli/rc30_compare_offline.php` сравнивает **два ранее полученных** отчёта RC30, не загружая `config.php`, не подключаясь к Moodle или базе данных. Это полезно, когда рабочий сервер временно недоступен или результаты нужно проверить на компьютере администратора.

## Требования

- PHP CLI 8.1+.
- Полная директория `local/kbacompany` с сервисами `classes/local/task_rc30_{integrity,acceptance,report_comparison}_service.php`.
- Два JSON-файла, сформированных командой `rc30_acceptance.php --format=json`.

Сравнение ничего не изменяет. Файлы ограничены 2 МБ, символьные ссылки на отчёты не принимаются. Если скопировать один и тот же JSON под другим именем, команда откажет с `report_duplicate_snapshot`.

## Пример

```bash
php local/kbacompany/cli/rc30_compare_offline.php \
  --baseline=rc30_before.json \
  --current=rc30_after.json \
  --format=json --strict > rc30_diff.json
```

При необходимости можно запустить команду без установленного Moodle, сохранив относительную структуру файлов плагина. Доступ к серверу или подключение к MySQL для этого не требуются.

## Коды завершения

| Код | Значение |
|---|---|
| 0 | Сравнение завершено без блокирующих отклонений |
| 1 | Сравнение выполнено, обнаружены блокирующие отклонения |
| 2 | Сравнение не удалось выполнить (ошибка файла, формата, происхождения) |

При `--format=json` ошибки сериализуются в JSON с безопасным кодом, без путей к файлам, SQL и текста исключений.

## Границы применимости

Отпечаток установки в отчёте не является цифровой подписью. Автономная проверка не подтверждает отсутствие вмешательства в файлы и не заменяет серверные PHPUnit, ручную проверку интерфейса, разграничения компаний, производительности и восстановление из резервной копии. Версия RC30 присваивается только после приёмки.

## Совместимость

Прежняя команда `cli/rc30_compare_reports.php` не изменена. В релизе нет SQL-миграций и изменений бизнес-данных.
