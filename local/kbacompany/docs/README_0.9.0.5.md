# local_kbacompany 0.9.0.5 — Установка и использование
Build 2026092417. База: 0.9.0.4 build 2026092416. Полный plugin root kbacompany/.

## Установка
Сначала резервная копия кода, БД и moodledata. Установить INSTALL_ME ZIP через
штатный механизм обновления Moodle либо заменить local/kbacompany на сервере
и выполнить штатный upgrade. Затем очистить кэши. Не загружать Release Kit
в установщик плагинов. Рабочий сервер в чате не обновлялся.

Целевое окружение Moodle 4.1.22, PHP 7.3+. Нужны штатные File API, fileinfo,
доступное хранилище moodledata и PHP ZipArchive для Office/OpenDocument.
На объём дополнительно влияют maxbytes Moodle, upload_max_filesize и
post_max_size PHP и ограничения веб-сервера. Максимум одного файла в плагине —
25 МиБ (26 214 400 байт), но фактический лимит может быть ниже.

## Новый документ
Управление → Документы → Создать документ. Заполнить название/тип,
выбрать «Файл этой версии» и сохранить черновик. Текст содержания необязателен,
когда файл прикреплён. До передачи на согласование можно готовить пустой
черновик; для согласования требуется текст или доступный основной файл.

## Изменение и версии
В черновике можно заменить основной файл с явным подтверждением. Обычное
сохранение черновика не создаёт новую редакцию. Для выпущенного документа
создать новую редакцию в «Действиях», открыть её редактирование, загрузить
новый файл и указать причину изменения. Предыдущая версия и её файл сохраняются.
Новая редакция обычного документа начинает работу с копией предыдущего файла.
Для нового снимка процесса/СТП старый файл намеренно не наследуется, чтобы
не представить его как файл обновлённого процесса; предыдущий файл остаётся в истории.

Скачать файл можно в «Обзоре» и в таблице «Версии». Доступ зависит от прав
на конкретную редакцию, а не от знания ссылки. Замена не переносит согласования
или ознакомления на другую редакцию. Действующая версия заменяется только
отдельным существующим действием ввода новой редакции в действие.

После ошибки формы выбранный файл нужно выбрать заново (ограничение браузера).
Та же форма не даст незаметно сохранить запись без ранее выбранного файла.
Чтобы отказаться от неудачной загрузки, отменить форму и открыть её заново.

Поддержаны PDF, DOCX, XLSX, PPTX, ODT, ODS, ODP, RTF, TXT, CSV.
Не добавлены legacy DOC/XLS/PPT, исполняемые файлы, архивы и макроформаты.
Файлы скачиваются; онлайн-редактирование, сравнение содержимого и предпросмотр
не входят в этот выпуск. Один основной файл на редакцию, без приложений-пакетов.

## Проверка
QA release evidence различает статические/изолированные/локальные HTTP и
Chromium component тесты от приёмки живого Moodle. PHP ZipArchive отсутствует
в сборочном контейнере: его отсутствие проверено, правила Office проверены
с тестовой заменой, но native Office/libzip path НЕ ЗАПУСКАЛСЯ.
