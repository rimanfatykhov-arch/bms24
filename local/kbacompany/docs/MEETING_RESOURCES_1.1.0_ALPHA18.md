# BMS24 — Ресурс встречи — 1.1.0-alpha18

## Цель
Добавить канонический справочник ресурсов встреч компании и безопасную привязку ресурса к BMS Meeting без отдельного booking-engine.

## Каноническая терминология
- Ресурс встречи
- Переговорная
- Место
- Ссылка для онлайн-встречи
- Занятость ресурса

## Модель
Новый company-scoped справочник `local_kbacompany_meetres` хранит только ресурс компании: UUID, код, название, тип, расположение, вместимость и active state.

Meeting остаётся единственным владельцем бронирования: в `local_kbacompany_meeting` добавлены `resourceuuid` и `onlineurl`.

## Правила
1. Ресурс выбирается только в пределах текущей Company.
2. Архивный ресурс нельзя выбрать для новой встречи.
3. Один ресурс нельзя забронировать на пересекающиеся интервалы.
4. Проверка двойного бронирования выполняется под resource lock.
5. Вместимость > 0 ограничивает число участников; 0 означает «не задано».
6. Онлайн-ссылка допускает только валидный HTTP/HTTPS URL.
7. Занятость ресурса видна компании, но название приватной встречи раскрывается только её участнику.
8. Calendar/Meeting не создают отдельную сущность бронирования.

## UI
- `/local/kbacompany/meeting_resources.php?uuid=...` — справочник и занятость ресурсов.
- В Meeting Create/Edit: «Ресурс встречи» + «Ссылка для онлайн-встречи».
- В карточке встречи: ресурс и кнопка «Подключиться онлайн».

## Совместимость
Существующие встречи получают пустые `resourceuuid`/`onlineurl` и продолжают работать без изменений.
