# Запуск управленческой недели — BMS 0.5.12

## Цепочка

`Фактическое назначение → Покрытие недели → Явный выбор руководителя → Проверяющий/наблюдатель → canonical Battle Plan`

## Правила

1. Экран покрытия является read-model и сам ничего не создаёт.
2. Руководитель вручную выбирает только те назначения, для которых нужно запустить неделю.
3. Сервер не доверяет токену формы как доказательству назначения: связь сотрудника с должностью повторно проверяется на выбранную неделю.
4. Один сотрудник на одной должности получает не более одного плана на неделю независимо от количества штатных слотов.
5. Повторная команда возвращает уже существующий план и не создаёт дубликат.
6. Проверяющий обязателен; наблюдатель необязателен.
7. Для запуска прошлой недели используется историческое назначение, а не текущий список должностей сотрудника.
8. Запуск не создаёт задачи и не активирует план автоматически: новый план остаётся в `draft` и проходит обычный жизненный цикл Боевого плана.

## Хранилище

Новых таблиц нет. Создаётся только существующая запись `local_kbacompany_bplan`; ограничения уникальности и существующий lifecycle остаются источником истины.
