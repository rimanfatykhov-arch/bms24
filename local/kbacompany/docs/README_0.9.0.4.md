# Установка local_kbacompany 0.9.0.4 / build 2026092416

INSTALL_ME — полный устанавливаемый плагин, корневая папка kbacompany/.
SOURCE — тот же исходный код без дополнительных внешних пакетов; архивы намеренно идентичны.
BMS_RELEASE_KIT_NOT_FOR_MOODLE_INSTALL — код, patch, отчёты и проверочные материалы.
Не загружайте Release Kit в установщик Moodle.

База: локальный INSTALL0.9.0.3, все его изменения включены.
Путь после установки: Управление → Документы → Создать документ → Сохранить черновик → Карточка.
Введение документа в действие выполняется отдельно, после рассмотрения, утверждения и публикации.
Существующие документы, UUID, коды, редакции, записи и согласования не пересоздаются.

Резервная копия БД, moodledata и code → обновить local_kbacompany штатным способом →
пройти Moodle upgrade → очистить кэши. Восстановление при неуспешном live upgrade —
по согласованной резервной копии; downgrade номера версии без восстановления БД не поддерживается.
Новых schema изменений в этом patch нет; ранние миграции при необходимости выполняет Moodle.

Перед production отдельно проверить: upgrade с используемой версии; обычный пользователь,
назначенный согласующий и управляющий; две компании; создание/редакция/рассмотрение;
активация и старые редакции; ознакомление и записи формы; source=stp; меню с KBA Theme;
мобильный экран и настоящие session/lock concurrency/recovery.
Статус ALPHA. Эти live-проверки в чате не запускались.
