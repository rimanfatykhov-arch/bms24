# Battle Plan Action Control — v0.5.8

## Каноническая цепочка
Показатель → состояние → governance event → canonical Task → Battle Plan → следующий факт.

## Контроль исполнения
- Статус берётся напрямую из `local_kbacompany_task.status`.
- Результат берётся напрямую из `local_kbacompany_task.result`.
- Прогресс рассчитывается только по `local_kbacompany_taskcheck`: done / total.
- При отсутствии checklist процент прогресса не синтезируется.

## Проверка следующей недели
Для Боевого плана недели W сервис ищет решение ровно недели W-7. Затем читает факты W-7 и W из append-only `statval` и вычисляет точное направление изменения без скрытых процентных порогов.

`up`: рост = улучшение, снижение = ухудшение.
`down`: снижение = улучшение, рост = ухудшение.
`neutral`: фиксируется изменение, но управленческая оценка не назначается.

Система не утверждает причинную связь между Task и изменением показателя.
