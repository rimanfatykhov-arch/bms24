# BMS v0.5.9 — Управленческий цикл по исключениям

Build: **2026091507**

## Что изменилось

- Management Exceptions теперь показывает управленческий цикл поверх существующих `stateevt`, canonical Task, Battle Plan и `statval`.
- Добавлен фильтр по циклу: требуется решение, решение без исполнения, просрочено, в работе, ожидается следующий факт, улучшилось, ухудшилось, без изменения, цикл закрыт.
- Для position-bound показателя показываются доступные Боевые планы текущей недели.
- Если canonical Task доступна пользователю, отображаются её статус, реальный checklist-прогресс и результат.
- После действия сравнивается только точный следующий недельный факт.
- Ухудшение/отсутствие изменения создаёт причину «требуется новое решение» только если более нового решения ещё нет.
- Task/Battle Plan ACL не обходится; скрытые Task details и их plan provenance не раскрываются.
- Релиз schema-neutral: новых таблиц, capabilities и external services нет.

## Архитектурная граница

Не создано отдельных Incident / ManagementAction / ActionStatus / Effect объектов. Источники истины остаются прежними.
