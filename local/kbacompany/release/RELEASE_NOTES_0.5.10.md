# BMS 0.5.10 — Управленческий обзор Боевых планов

Build: 2026091508.

## Что добавлено

- Новый schema-neutral экран `battle_plan_overview.php`.
- Оперативная агрегация активных (не закрытых) Боевых планов выбранной недели.
- Фильтры: неделя, подразделение (`position -> orgnode`), руководитель/проверяющий, тип внимания.
- Сводка по подразделениям и руководителям.
- Для каждого плана показываются критические position-bound показатели, критические исключения, исключения требующие решения, открытые/просроченные canonical Tasks.
- Прямой переход в конкретный Боевой план и Management Exceptions.

## Архитектура

Нового хранилища нет. Обзор вычисляется из существующих `bplan/bplanitem`, `position/orgnode`, `statbind`, Management Exceptions и canonical Task. Закрытые планы исключаются из оперативной выборки. ACL canonical Task не обходится: учитываются только задачи, которые пользователь может видеть через `task_service::can_view_task()`.

## Совместимость

Moodle 4.1.22 / PHP 7.3. Схема БД, capabilities, external services и privacy provider не меняются.
