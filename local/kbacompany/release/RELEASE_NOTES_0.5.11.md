# BMS v0.5.11 — Покрытие Боевых планов и управленческие пробелы

Build: `2026091509`

## Что добавлено

- Read-only экран «Покрытие Боевых планов».
- Покрытие фактических назначений сотрудников недельными Боевыми планами.
- Пробел «назначение без Боевого плана».
- Пробел «должность без критических показателей».
- Пробел «критический показатель без действующей нормы».
- Агрегация пробелов по подразделениям.
- Прямые переходы к созданию Боевого плана и настройке канонических показателей/норм.

## Архитектура

Релиз schema-neutral. Никакие Gap/Control/Incident сущности не создаются. Read-model использует существующие `posassign`, `position`, `orgnode`, `bplan`, `statbind` и `statnorm`. Исторические назначения определяются по `effectivefrom/effectiveto`; нормы разрешаются по выбранной неделе через существующую историю редакций.
