# BMS24 RC29 build2026101630 — Реестр регулярных задач: фильтр и навигация

Дата: 16.10.2026. База: build2026101629.

## Причина изменения
По рабочему скриншоту BMS24 реестр содержит активные, черновые и архивные серии без фильтра. Регулярные задачи доступны из боевого плана, но не выделены в рабочем меню. Рабочие регулярные определения важны для ежедневной операционной работы.

## Изменения
1. `recurring_tasks.php?view=list`: серверный GET-фильтр `status=all|draft|active|paused|archived` с русской меткой «Состояние серии», кнопками «Показать» и «Сбросить фильтр», счётчиками по доступным сериям. По умолчанию — все. При пустой выборке отдельное сообщение и сброс. Состояние фильтра сохраняется в URL карточки, создании/редактировании и при возврате из них. Контекст `uuid` и необязательного `plan` сохраняется.
2. Фильтр применяется **после** `recurring_task_service::context(company, actor)`, то есть после авторизации, company scope и штатного ограничения видимых серий. Он не расширяет доступ и не меняет lifecycle.
3. `bms_ui_service::routes()` / `navigation_groups()`: отдельный бизнес-пункт «Регулярные задачи» сразу под «Задачами» в группе «Рабочее пространство». Адрес — `recurring_tasks.php?uuid=<companyuuid>&view=list`. Иконка цикла из BMS UI; KBA Theme не меняется. При открытии реестра, карточки или библиотеки новый пункт активен.
4. Реестр на узких экранах прокручивает широкую таблицу внутри своего контейнера, не растягивая App Shell.
5. Добавлены RU/EN переводы и PHPUnit-проверка порядка/ссылки/подсветки навигации.
6. Версия/savepoint — `2026101630`, без DDL.

## Сохранено
Схема БД, модели TaskDefinition/TaskOccurrence, CRUD карточки, генератор cron, UUID/revisions, права и изоляция компании, связь с боевыми планами, исходный список серий и история задач. Не создаются дубли и не выполняется автоматическая синхронизация с согласованными планами.
