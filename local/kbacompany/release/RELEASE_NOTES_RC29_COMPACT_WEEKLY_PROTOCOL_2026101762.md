# BMS24 1.1.0-rc29 — build2026101762

## Еженедельная координация: компактные протоколы

- До 30 доступных задач отображаются свернутыми строками с сотрудником, названием задачи и текущим статусом решения.
- Формы редактирования и история редакций раскрываются по клику на строку (нативный HTML details).
- Фильтр: все решения, ожидает, в работе, выполнено, отменено, без протокола. Фильтрация производится в уже доступной пользователю выборке задач.
- Прямой переход из реестра открывает нужную строку даже при отличающемся статусном фильтре.
- После сохранения или смены статуса сохраняется фильтр и фокус на выбранном решении.
- Бизнес-логика, ACL, хранение решений и Task Center не изменены; новых таблиц нет.

## Ограничения

- Фильтр действует на первые 30 отображаемых задач. Это не глобальный фильтр общего реестра.
- Требуется приёмка на живом Moodle; статическая проверка не заменяет тесты UI.
