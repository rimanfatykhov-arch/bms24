# BMS24 RC29 / build2026101637 — Position Coverage 03 / Боевые планы (read-only)

**База:** RC29 / build2026101636. Moodle 4.0/4.1, `local_kbacompany`. **Статус:** staging candidate — runtime Moodle/ACL acceptance NOT RUN.

## Реализовано

1. Менеджеру, который имеет подтверждённое company-scoped право управления замещениями и право открыть выбранный боевой план, показан отдельный **информационный блок о согласованных замещениях**. Блок соответствует `positionuuid` и `userid` первоначального владельца плана и включительным датам выбранной недели.
2. Отдельно показаны ФИО замещающего, даты начала и окончания, статус «Сейчас исполняет» (только если canonical `effective_executor()` действительно подтверждает текущего исполнителя) или «Согласованное замещение (не действует сейчас)». При отсутствии замещения блок не выводится. Ссылка на карточку замещения открывается через действующие серверные ACL.
3. Для вкладки «Метрики» при наличии замещения выводится ясное предупреждение: **доступ к вводу факта, изменению планов показателей и согласованию не передаётся замещающему автоматически**.
4. Сервис `position_coverage_service::battle_plan_window()` read-only, фильтрует по компании, должности, исходному пользователю, approved статусу, scope `position_work` и пересечению дат. Сначала проверяет manager ACL. `battle_plan_service::context()` использует метод только после авторизованного разрешения выбранного плана.
5. Изменения не затрагивают `bplan.userid`, согласования `approvedby/approvedat`, версии метрик, права на факт/план, `task.assigneeid`, генератор регулярных задач, параметры рабочего/личного календаря, private discussions. Доступ к самому боевому плану не расширяется.

## Файлы кода

- `classes/local/position_coverage_service.php` — readonly проекция согласованных замещений;
- `classes/local/battle_plan_service.php` — опциональная ACL-scoped проекция для выбранного плана;
- `classes/local/battle_plan_ui_service.php` — информативный блок в карточке;
- `battle_plan.php` — пояснение на вкладке метрик;
- `lang/ru|en/local_kbacompany.php` — шесть новых переводов;
- `tests/{position_task_coverage_test,battle_plan_service_test}.php` — дополнительные regression assertions (не выполнялись с Moodle DB).
