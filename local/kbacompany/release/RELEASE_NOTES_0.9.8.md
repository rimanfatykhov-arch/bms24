# local_kbacompany 0.9.8 — IDEF0 Decomposition

Build: 2026100502
Status: ALPHA

Adds IDEF0 decomposition as a presentation of the existing canonical Process L0/L1/L2 hierarchy. It calculates A-0/A0/A1/A11 notation, renders visible child processes on the IDEF0 tab, links parent/child navigation, and reuses existing Process CRUD for child creation. No second IDEF0 tree, schema, ACL, inter-function arrows or SIPOC writes are introduced.
