# BMS24 1.1.0-rc29 build2026101820 — единый контроль внедрения

**Изменён только local_kbacompany.** Corporate 0.40.8 / API 1.26 остаётся без изменений.

- Новая страница `implementation_project_dashboard.php` для **руководителя со всеми действующими правами управления проектом**.
- Сводка разделов и задач подтверждённого аудита, недельного включения в Боевые планы и текущих решений куратора.
- Принятые результаты отделены от задач, завершённых без подтверждений.
- В экране отображается назначенный в Corporate куратор, при наличии прав — переход к существующей странице редактирования программы, панели куратора Corporate и списку «Ученики куратора».
- Установка не создаёт куратора, не назначает разрешения и не даёт куратору доступ к внутренним проектам чужой компании.
- Куратор назначается в Corporate: `/local/kbacorporate/implementation_program_edit.php?companyid=...&auditid=...`, поле «Куратор внедрения»; далее использует `/local/kbacorporate/implementation_curator.php`.
- Сводка сохраняет отдельные состояния `week_complete` и `result_complete`; при неполных данных показываются прочерки и предупреждения, а не нули.
- Очередь статусов не более 12 задач, исходные карточки находятся в Corporate; нет копирования или изменения данных.
- Новый интерфейс доступен из списка связанных проектов и подробного экрана этапов.
- Таблицы БД и жизненные циклы задач не изменены, добавлен штатный checkpoint миграции.

## Установка и приёмка

1. Создать резервную копию БД и обоих плагинов, установить на тестовый Moodle.
2. Убедиться, что Corporate 0.40.8 API 1.26 установлен и BMS24 обновился до `2026101820`.
3. Под управляющим пользователем открыть Административная шкала → Проекты внедрения BMS → Панель контроля внедрения.
4. Сверить недельную привязку задач и текущие решения куратора с исходными страницами; проверить программу без аудита и права на Боевые планы.
5. Назначить куратора в существующей форме Corporate и убедиться в обновлении имени на панели и доступе назначенного пользователя к «Ученикам куратора».
6. Проверить пользователя без полномочий, чужую компанию, неоплаченные программы, архивный проект и задачи без подтверждений.
7. Проверить совместимость с Moodle 4.1.22, PHP 8.1.34 и MySQL 5.7.21; серверная E2E здесь не выполнялась.

## Ограничения

Панель BMS24 предназначена для **управляющих компании**, а кабинет куратора остаётся отдельным рабочим пространством Corporate. Доступ к панели не открывается куратору только на основании назначения: доступом управляют действующие права обеих систем. Для отдельного персонального дашборда куратора необходим следующий релиз с самостоятельной проверкой прав Corporate.
