# BMS v0.5.6 — Показатели должности в Боевом плане

Build: `2026091504`

## Цель

Связать недельный Боевой план с единым реестром показателей без создания отдельного набора KPI, квот или фактов внутри Боевого плана.

## Реализовано

Верх выбранного Боевого плана показывает недельные показатели, канонически связанные с должностью через `local_kbacompany_statbind`:

`Показатель | Прошлая неделя | Квота / норма | Состояние | Факт текущей недели | Динамика`.

Действующая норма берётся из версионного `statnorm` на дату недели. Для тренда и состояния берутся до 52 последних периодов истории, заканчивающихся неделей плана, поэтому старый Боевой план не теряет свою историю из-за более новых данных и не видит будущие факты. Подтверждение руководителя из `stateevt` имеет приоритет над автоматическим состоянием только для того же фактического периода. Связанная canonical Task показывается при наличии права на её просмотр.

Ввод факта из Боевого плана создаёт новую ревизию в `local_kbacompany_statval`. Исправление уже существующего факта требует причины. Определение показателя не копируется.

Legacy `bpnorm`/pinned quota UI сохранён как compatibility layer для ранее созданных планов и явно отделён от канонического контура.

## Схема

Schema-neutral. `install.xml`, `access.php` и `services.php` не меняются. В `upgrade.php` добавлен только schema-neutral savepoint `2026091504`; DDL отсутствует.
