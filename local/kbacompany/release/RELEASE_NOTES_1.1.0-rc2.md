# 1.1.0-rc2 — Task Center self-review and creation-form usability — build 2026101216

- Canonical BMS Task now allows the assignee and reviewer to be the same company employee.
- Self-reviewed work preserves the two-step lifecycle: submit result -> review -> accept.
- Self-assigned/self-reviewed tasks remain in the `My tasks` scope because that scope is canonically assignee-based.
- `Add to Battle Plan` and `File (optional)` are now visible directly in the create/edit form instead of being hidden under Advanced.
- Reviewer help text explains the supported self-review workflow.
- No database schema, capability or privacy-storage change.
