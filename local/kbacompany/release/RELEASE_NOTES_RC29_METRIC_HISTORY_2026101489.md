# RC29 build2026101489 — история изменений метрик

Вкладка «Метрики → Ввод данных»: раскрываемый журнал по выбранной метрике, фильтр даты, факт/план, значение до/после, автор, дата и причина. Источник — существующий append-only local_kbacompany_statval. Журнал ограничен компанией и метрикой; до 100 записей за просмотр. Данные не мигрируются, не перезаписываются.

Требуется проверка в работающем Moodle и сценарии со сменой полномочий.
