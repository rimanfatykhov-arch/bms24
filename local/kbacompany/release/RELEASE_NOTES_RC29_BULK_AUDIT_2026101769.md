# BMS24 RC29 build2026101769 — журнал групповых операций

Добавлен неизменяемый журнал подтверждённых групповых операций в реестре решений. Записываются компания, исполнитель, тип операции, выбранное количество, обновлённые и пропущенные записи, время. При предварительном просмотре запись не создаётся. Уровень детализации — одна запись на массовый запуск (не журнал каждой попытки по каждой задаче). Просмотр доступен по текущим управленческим правам компании; последние 20 записей показаны в раскрываемой таблице. Старые операции не восстанавливаются.

**Миграция**: таблица `local_kbacompany_bp_baudit` для нового и обновляемого Moodle. Необходим запуск штатного обновления БД.

**Ограничение**: если запрос прошёл частично, результат записывается общим счётчиком без перечня конкретных исключений. Работа на действующем Moodle не проверялась.
