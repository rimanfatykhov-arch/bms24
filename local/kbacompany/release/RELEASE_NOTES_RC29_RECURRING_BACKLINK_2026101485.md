# RC29 build2026101485 — Возврат из регулярных задач в боевой план

- Из библиотеки, открытой из боевого плана (`plan=...`), параметр возвращается при установке шаблона регулярной задачи.
- На странице регулярной задачи появляется заметная кнопка «Вернуться к боевому плану» (вкладка «Задачи»).
- Контекст сохраняется при сохранении/активации серии, переходе между сериями и в библиотеку.
- Перед показом ссылки сервер проверяет доступ к конкретному плану через `battle_plan_service::context`, отдельно от доступа к серии.
- Прямое открытие регулярной задачи без `plan` сохраняет прежнее поведение. Новых таблиц нет.
- Не меняется семантика создания серии: это не автоматическое добавление экземпляра в недельный план.
- Требуется приемка в работающем Moodle.
