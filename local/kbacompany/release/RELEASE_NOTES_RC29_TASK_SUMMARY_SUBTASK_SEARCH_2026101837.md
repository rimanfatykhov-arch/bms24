### Исправления сводки

1. **Незавершённые → список задач.** Ссылка теперь применяет `signal=open`, а SQL использует `t.status NOT IN ('done','cancelled')` после проверок компании, видимости и всех исходных фильтров. Ранее KPI отображал верное число, но переход не применял нужный фильтр.
2. **Выполнение в %.** Из знаменателя исключаются отменённые задачи: `done / (total - cancelled)`. Счётчик «Всего» по-прежнему включает отменённые, чтобы не скрывать факт их существования.
3. **Детализация по исполнителям.** Счётчики незавершённых, на приёмке, просроченных, возвращённых и завершённых задач стали прямыми ссылками на соответствующий список с исходными правами и фильтром исполнителя.
4. **Детализация по проектам.** Цифры по проектам открывают соответствующие списки с сохранением фильтра проекта и других ограничений. Существующее правило: считаются только прямые связи задачи с проектом; связи подзадач через родителя в проектную сводку не включаются.
5. **Ближайшие семь дней.** Диапазон включая сегодня теперь заканчивается шестым следующим календарным днём (ровно семь календарных дат). Одинаковые границы действуют в KPI и списке.
6. **Пустые выборки и сроки.** При отсутствии задач показывается текст; если в таблице проблемных задач отсутствует крайний срок, отображается «Без срока».

Форма «Связать существующую» получила живой поиск: подсказки при вводе от двух символов, выбор задачи одним кликом, отображение срока и короткого идентификатора, управление клавиатурой. При недоступности JS или сервера подсказок остаётся прежний поиск по кнопке.

### Установка и приёмка

1. Создайте резервную копию файлов `local/kbacompany` и БД.
2. Установите полный ZIP версии `2026101837` поверх предыдущего `local_kbacompany` по штатной процедуре Moodle.
3. Запустите `/admin/index.php`, затем очистите кэши Moodle и браузера.
4. Проверьте **Задачи → Сводка → Незавершённые**: в списке не должны быть выполненные/отменённые задачи.
5. Проверьте процент при наличии отменённых задач, «Срок в ближайшие 7 дней», а также переходы из таблиц сотрудников и проектов.
6. Откройте карточку задачи → «Связать существующую», введите 2–3 символа и выберите нужную задачу из подсказок.
7. Выполните те же действия под руководителем и обычным сотрудником, проверив отсутствие чужих задач.
