# BMS24 — local_kbacompany 1.1.0-rc29 — build2026101838

## Назначение
Хотфикс «Восстановление раздела Задачи / переходов из Сводки» для установки поверх `build2026101837`. Это **полный накопительный пакет**, а не дифф или набор заменяемых файлов.

## Исправленные дефекты

1. **PHP TypeError при переходе из сводки в фильтрованный список задач.** В `classes/local/task_ui_service.php` на строках 253 и 258 вызовы `html_writer::tag('span', ...)` передавали третий аргумент строкой `bms24-task-signal-chip`. Исправлено на массив `['class' => 'bms24-task-signal-chip']`. Это устраняет указанную первопричину для фильтров показателя, исполнителя и проекта.
2. **PHP Warning при загрузке RU/EN локализации.** В `lang/ru/local_kbacompany.php` и `lang/en/local_kbacompany.php` строка `battleplan_weekcoord_pattern_task_description` содержала интерполируемые `{$a->...}` внутри PHP double-quoted string. Это вызывало обращения к неопределённой переменной `$a` при загрузке языкового файла. В шаблоне экранированы символы `$` так, чтобы подстановки `{$a->signal}`, `{$a->rule}`, `{$a->weeks}`, `{$a->employee}`, `{$a->position}` сохранились для `get_string()` Moodle.
