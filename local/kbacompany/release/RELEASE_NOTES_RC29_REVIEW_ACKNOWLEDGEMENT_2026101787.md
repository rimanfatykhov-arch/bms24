# BMS24 RC29 build2026101787 — Подтверждение исправления замечаний

- В возвращённом черновике сотрудник отмечает исправление каждого замечания с пояснением.
- Руководитель принимает исправление либо возвращает его на доработку (с обязательным пояснением).
- Хронология событий хранится в `statepayload.review_correction_events`; уникальная связка замечания: отметка времени, автор, текст, идентификатор задачи.
- Операции защищены Moodle sesskey, edit token, lock и доступом к плану/роли.
- Исходные задачи и статус согласования не меняются автоматически.
- Для просмотра актуального состояния используйте возвращённый черновик.
- Статическая проверка и ZIP не равны проверке на живом Moodle.
