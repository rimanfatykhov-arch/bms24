- Плагин: `local_kbacompany`
- Линия: `1.1.0-rc29`
- Build: `2026101831`
- Основа: `2026101830` (Чек-лист 2.0)
- Миграции БД: нет
- Плагины `local_kbacorporate`, `mod_kbaelement`: без изменений

## Функциональность

1. На вкладке «Обзор» карточки задачи отображается самостоятельный блок «Подзадачи»: название, статус, исполнитель, крайний срок, переход к карточке. Пагинация по 20 видимым пользователю задачам.
2. Кнопка «Создать подзадачу» открывает существующую форму задачи с предварительно выбранным родителем. У дочерней задачи собственные исполнитель, срок, ожидаемый результат, история, сообщения.
3. Кнопка «Связать существующую» открывает защищённую форму поиска, доступную только пользователю, который может изменять структуру родительской задачи. Выборка ограничена 50 доступными записями, предусмотрен поиск по названию.
4. Связывание изменяет лишь `parentuuid`, ревизию и дату изменения существующей задачи; запись не дублируется, членство в Боевом плане не меняется, сохраняются история и обсуждения. Для родителя и подзадачи создаются записи в журнале.
5. Права: проверяются компания, доступ к родителю и право декомпозиции, право автора или руководителя на связываемую задачу. Нельзя использовать закрытую задачу, задачу с другим родителем или управленческим контекстом, а также автоматически созданную задачу.
6. Защита от циклов, проверка версии записи, блокировки при изменении и POST/sesskey.

## Границы релиза

- Сводный процент выполнения дочерних задач, автоматический запрет закрытия родителя и управление иерархией в дереве — запланированы на 1832.
- Родитель не завершает дочернюю задачу и не закрывается автоматически.
- Список содержит только дочерние задачи, доступные пользователю по действующей модели прав. Закрытые чужие данные не раскрываются.
- Привязка задачи, которая уже имеет родителя, выполняется через существующее редактирование с его правилами (без автоматического переназначения из новой формы).

## Инструкция по установке

1. Сохраните резервные копии каталога `local/kbacompany` и БД Moodle.
2. Установите ZIP через стандартный менеджер плагинов или замените файлы каталога на тестовом стенде.
3. Выполните обновление Moodle до build `2026101831`, очистите кэши.
4. Откройте активную задачу на вкладке «Обзор».
5. Проверьте «Создать подзадачу» и «Связать существующую» в двух учётных записях, а также вход пользователем другой компании.
6. Убедитесь, что связанная задача осталась в прежнем Боевом плане и её история сохранилась.
