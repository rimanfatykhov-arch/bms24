# local_kbacompany 1.1.0-rc8 — Метрики 2.1 CRUD BMS24

Build: `2026101224`

## Что изменено

- Раздел «Все метрики» переименован в понятный пользователю «Реестр метрик».
- На любом экране раздела доступны явные действия «Создать метрику» и «Управлять метриками».
- Реестр получил полноценный BMS24 CRUD-контур: создание, чтение/карточка, редактирование, архивирование и восстановление.
- Добавлены поиск по названию/коду/единице измерения и фильтр Активные / Архив / Все.
- Добавлена сводка по активным, главным, архивным и общему количеству метрик.
- В таблице реестра есть прямые действия: открыть карточку, внести факт, архивировать/восстановить.
- Создание и редактирование перестроены в понятную форму: основные управленческие поля видны сразу, источник и агрегация находятся в дополнительных настройках.
- «Удаление» реализовано безопасно через архив: UUID, факты, планы, нормы и связи не удаляются. Архивная метрика может быть восстановлена.
- При архивировании метрика автоматически снимается с роли «Главная метрика компании» и перестаёт отображаться в Информационном центре.
- Схема БД, capabilities и privacy storage не менялись.

## Acceptance focus

1. Создать метрику из Информационного центра через кнопку «Создать метрику».
2. Найти её через поиск в Реестре метрик.
3. Открыть карточку, изменить название/описание и сохранить без смены UUID.
4. Внести факт через прямое действие.
5. Архивировать метрику — она исчезает из активного реестра и Информационного центра.
6. Переключить фильтр на «В архиве» и восстановить метрику.
7. Убедиться, что после восстановления история фактов и связи сохранены.
