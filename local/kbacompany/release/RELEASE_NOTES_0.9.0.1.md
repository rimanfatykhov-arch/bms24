# RELEASE NOTES — local_kbacompany 0.9.0.1 build 2026092413

## Задача и граница

Упорядочить меню по скриншоту FireShot Capture 088, страница 1: убрать длинную прокручиваемую
строку разделов, неоднозначные названия и дублирующиеся навигационные кнопки.
Никаких новых управленческих, AI, learning или интеграционных контуров.
Основа: INSTALL 0.9.0, SHA256 `0034c72d7cfb4d12862eebfc2f6acbe7accd5b5887423987d6f9695a838c90cc`.

## Изменено

- Верхняя навигация управления: пять групп и контекстная вторая строка (максимум четыре пункта).
- Подсветка выбранного раздела и текущей страницы; семантические списки ссылок,
  `aria-current`, видимый фокус и работа без JavaScript.
- Подменю добавлено на связанные страницы Показателей, Боевого плана,
  Управленческой недели и Исполнения: после перехода не теряется путь обратно.
- Выбранная неделя передаётся только тем страницам, которые уже поддерживают параметр `week`.
  Это не обещание сохранить период при переходе через страницу без параметра недели.
- Существующая `can_manage_management` используется для видимости управленческих ссылок.
  Domain ACL, полномочия owner/curator/manager/employee и границы компаний не изменены.
- «Административная шкала» перенесена в «Архитектуру», «Показатели» — в «Управление».
- В боковом меню появился прямой переход к существующим «Управленческим циклам».
  Прежний `administrative_cycle.php` подписан «Исполнение и встречи», чтобы не путать два экрана.
- Для скрытых дочерних маршрутов подсвечивается видимый родитель меню; исходный active route
  дерева архитектуры сохраняется. В Task Center подсвечиваются «Задачи», а не «Коммуникации».
- В обзоре управления удалены три повторяющиеся кнопки перехода; сами разделы не удалены.
- `[[open]]` в карточках цепочки управления заменён на локализованное «Открыть».

## Не изменено

Byte-identical относительно 0.9.0: db/install.xml, db/upgrade.php, db/access.php,
db/services.php, db/tasks.php, privacy provider и все domain/integration/AI classes.
Из классов менялись только bms_ui_service и bms_workspace_ux_service (presentation/navigation).
Company UUID сохраняется в ссылках. Меню не создаёт, не копирует и не изменяет бизнес-записи.
Никакого transport/actual sync Odoo или Bitrix в этом патче нет.
KBA Theme и local_kbaai не переупаковываются, новых плагинов нет.
