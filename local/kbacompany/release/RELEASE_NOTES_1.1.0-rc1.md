# local_kbacompany 1.1.0-rc1 — Calendar Release Candidate 1

Build 2026101215.

This release candidate freezes the BMS24 Calendar 1.1 functional contract after beta2 hardening. No new business feature, schema, capability, scheduled task, integration provider, or privacy-storage contract is introduced in rc1.

RC1 acceptance scope covers Month/Week/Day/Analytics views, manual learning-calendar CRUD, BMS task/meeting/Battle Plan/management-cycle projections, recurrence, Meeting Time Finder, notifications and preferences, management rhythm, planning-meeting workflow, Meeting Resources, Google Calendar provider, large-company pagination, cron overlap protection, timezone/DST handling, Company isolation, role boundaries, upgrade/fresh-install packaging, and regression against non-calendar BMS24 contours.

Production readiness remains blocked until live Moodle 4.1.22 acceptance, real database upgrade, cron, Google OAuth/API, mobile/browser and role/company-isolation checks pass on the target environment.
