# BMS24 1.1.0-rc29 build2026101653

## Battle Plan — Metrics Card UI

- Replaced the canonical position-metrics table with management-oriented metric cards.
- Each metric is now presented as one object with Plan, Fact, Variance, Status and Trend zones.
- Daily fact values are shown as a compact seven-day strip for daily aggregate metrics.
- Existing inline Plan and Fact forms, status/action controls, permissions and service data remain canonical.
- Responsive layout collapses from a five-zone desktop grid to two columns and then one column on mobile.
- Presentation only: no schema, ACL, privacy or company-isolation changes.
