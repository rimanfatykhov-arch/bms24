# BMS24 — local_kbacompany 1.1.0-rc29 · build2026101840

**Дата:** 27 октября 2026 г.\
**Тип:** накопительный INSTALL ZIP, следующий после build2026101839.\
**Название:** Task Workspace UI 4.0 — Все мои роли + компактное рабочее пространство.

## Задача релиза

Показывать в разделе «Задачи» **по умолчанию все задачи, в которых пользователь участвует в любой реализованной роли**, по аналогии с «Все роли» Битрикс24, без переходов между отдельными вкладками. Представить фильтры компактно, не затрагивая модель данных, бизнес-процессы и права.

## Что изменено

1. **Новый scope `roles` (по умолчанию).** Объединяет в один запрос задачи пользователя как исполнителя (включая утверждённое временное замещение), постановщика, принимающего/проверяющего, наблюдателя и участника связанного Боевого плана. `EXISTS`-условия для Боевых планов не создают дублей. Ограничения `companyuuid`, `projection_access()` и проверка прав сохраняются.
2. **Scope `all` остаётся административным.** Руководитель в режиме «Все мои роли» видит только задачи, относящиеся к нему; все задачи компании — отдельная вкладка. Запрос `scope=all` от сотрудника без полномочий нормализуется к `roles`, а не повышает права.
3. **Существующие ссылки совместимы.** Режимы `my`, `created`, `review`, `watching`, `overdue`, `all` сохранены; особенно `review` по-прежнему означает *ожидающие моей приёмки*, тогда как `roles` включает задачи принимающего в любом состоянии.
4. **Счётчики вкладок.** Один ограниченный текущей компанией/ACL агрегирующий SQL-запрос, не зависящий от текущей страницы пагинации.
5. **Компактный интерфейс в BMS24 owned UI.** Уменьшена высота заголовка и вкладок; быстрый поиск по названию вынесен выше списка; быстрый отбор по текущим состояниям и срокам; остальные поля находятся внутри раскрываемого блока «Дополнительные фильтры». При активных расширенных фильтрах блок открывается автоматически.
6. **Поиск с прогрессивным улучшением.** Стандартная GET-форма работает без JS. При наличии JS введён debounce 650 мс; источник данных и права проверяются серверным кодом как раньше. Отборы/представление/контекст компании сохраняются при поиске и переходах.
7. **Улучшена читаемость списка/доски.** В списке появился столбец «Постановщик», у задач — метки непосредственных ролей пользователя; для доступа через Боевой план без непосредственной роли показывается отдельная метка. Названия, данные людей и пользовательский ввод экранируются.
8. **Локализация RU/EN и PHPUnit-тесты.** Добавлены 12 пар строк и `tests/task_roles_workspace1840_test.php`. Контракт Task Center поднят до `0.5.8`, версия плагина — `2026101840`.

## Не изменено

- Таблицы БД, структура install.xml, upgrade.php и хранимые данные.
- API создания, редактирования, приёмки, подзадач и чек-листов.
- Рабочая логика Боевым планов и сохранённых связей.
- Legacy-режим оформления (кроме появления роли `roles` в переключателе и счётчиков).
- Названия URL и существующие deep links.

## Установка

1. Сделать резервную копию базы и каталога `local/kbacompany`.
2. Установить **полный** архив `INSTALL_local_kbacompany_1.1.0-rc29_build2026101840.zip` как обновление текущего `local_kbacompany`, не смешивать отдельные файлы старого плагина.
3. Открыть `https://edu.kzn.mba/admin/index.php`, завершить обновление версии `2026101840`.
4. Очистить кэши Moodle.
5. Открыть `/local/kbacompany/tasks.php?uuid=<UUID_КОМПАНИИ>` **без** параметра `scope` и проверить, что выбрана вкладка «Все мои роли».
6. Проверить одновременно роль исполнителя/постановщика/принимающего/наблюдателя, а также отображение задач с несколькими ролями один раз.
7. Отдельно проверить пользователем без прав руководителя, что «Все задачи компании» отсутствуют и `scope=all` не раскрывает чужие задачи.
8. Проверить поиск, дополнительные фильтры, список, доску, сводку, ссылки из Боевых планов, карточку и создание задач, в том числе после смены фильтров.

## Область дальнейших улучшений

- Модель нескольких **соисполнителей** сейчас не добавлялась: в данном релизе использованы только роли реально существующей схемы BMS24.
- Массовые действия, настройка столбцов, сортировка, активность, полноценный режим сроков запланированы на build1841+.
- Битрикс24 не интегрируется автоматически; никаких задач из внешней CRM этот релиз не импортирует.

**Важно:** это результаты локальной сборки и изолированных тестов. Установка и полноценный прогон на `edu.kzn.mba` ещё не подтверждены.
