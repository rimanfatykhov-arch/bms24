# R3 · Первое подразделение

Кандидат для stage41 поверх R2 (2026110301). Миграций данных при установке нет.

В новой компании откройте создание должности, укажите название и нажмите «Подготовить первое подразделение». Во второй вкладке задайте название отдела, добавьте в проект должность руководителя и функцию с ответственным. Отправьте проект на согласование, утвердите и примените. Если в компании ещё нет филиалов, форма предложит создать основной филиал при применении. Все изменения действующей структуры выполняются в одной транзакции.

Вернитесь на вкладку должности, нажмите «Найти», выберите появившийся отдел и сохраните должность. Проверьте исходные значения полей, карточку должности и фильтр готовности R2.

Приёмка на stage41 должна также проверить отказ для пользователя без прав, изоляцию двух компаний и отказ при повторной попытке применить конкурирующий проект первого подразделения.
