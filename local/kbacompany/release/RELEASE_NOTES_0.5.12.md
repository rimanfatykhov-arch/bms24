# BMS 0.5.12 — Запуск управленческой недели

Build: `2026091510`

## Что добавлено

Экран «Покрытие Боевых планов» теперь позволяет руководителю явно отметить назначения без плана, выбрать проверяющего и при необходимости наблюдателя и создать недостающие недельные Боевые планы одной командой.

## Архитектурные границы

- План создаётся только после явного выбора руководителя; наличие назначения не является триггером автосоздания.
- Один канонический план по-прежнему определяется уникальной связкой `company + employee + position + week`.
- Повторная отправка безопасна: существующий план переиспользуется.
- Историческое назначение повторно проверяется на сервере по `effectivefrom/effectiveto` выбранной недели.
- Обычный путь `battle_plan_service::create_plan()` не ослаблен и продолжает требовать текущую должность.
- Новый orchestration-service не создаёт собственной таблицы и пишет только через канонический Battle Plan service.
- Релиз не меняет схему, capability-модель, external services или privacy provider.

## Не заявляется как проверенное

Moodle PHPUnit, browser E2E и production upgrade не считаются пройденными, если они не запускались отдельно в целевом окружении.
