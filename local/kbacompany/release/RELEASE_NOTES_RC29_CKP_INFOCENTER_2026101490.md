# RC29 build2026101490 — ЦКП и Информационный центр

- Название ЦКП: расширенное поле на 4 строки. Критерии приёмки: 6 строк, ширина 100%.
- Код ЦКП генерируется на сервере как CKP-XXXXXXXXXXXX на основе случайного UUID; ввод и изменение кода через форму невозможны. Прежние коды не изменяются.
- Отдельная read-only страница information_center.php: ЦКП сгруппированы по компании/активным подразделениям/должностям, связанные метрики, последний доступный план/факт. Исходные реестры не дублируются.
- Ограничения: информационный центр пока табличный, а не полноценная графическая инфодоска как на образце. Данные по метрикам строятся из существующего реестра; одиночные ЦКП без связанной метрики показываются без графика. Нужна приёмка на работающем Moodle.
