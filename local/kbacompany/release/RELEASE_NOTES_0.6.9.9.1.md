# BMS 0.6.9.9.1 — Русская терминология бизнес-модели

Build `2026092201`.

Russian Business Model Canvas UI now uses Russian terms as the primary business vocabulary. Internal enum values/codes remain unchanged for compatibility.

- Требование собственника instead of REQ.
- Как есть instead of AS-IS.
- Факт / Требуются данные / Гипотеза / Открытый вопрос instead of FACT / DATA / HYP / OPEN.
- Как должно быть / Целевое состояние instead of TARGET.
- Разрыв instead of GAP.
- Способ изменения instead of change mechanism.
- Показатель результата instead of KPI.
- Evidence counters and BMC cards no longer hard-code English abbreviations in the Russian UI.
- Legacy/technical wording in the new BMC screens is replaced with Russian equivalents.

No schema, ACL, services, snapshot, Owner Requirement pinning or domain-boundary changes.
