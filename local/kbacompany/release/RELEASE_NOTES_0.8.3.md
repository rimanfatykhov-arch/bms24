# 0.8.3 — Management Decision History & Learning

- Added `История решений` to the Management workspace navigation.
- Added BMS24-standard KPI cards for recorded decisions, repeated bindings, decisions with actions and decisions without actions.
- Added searchable management decision history using canonical append-only state events.
- Added descriptive recurrence markers for repeated indicator/context cases.
- Reuses canonical Task/Battle Plan execution links and their existing access rules.
- No new database tables, capabilities, services or privacy entities.
- Recurrence and later indicator movement are descriptive only and do not automatically establish root cause or causality.
