# BMS24 RC29 · build2026101631

## История изменений регулярной задачи (BMS CRUD)

Основа: полный исходник `build2026101630`. Изменения реализованы внутри `local_kbacompany` без нового реестра регулярных задач и без изменения механизма генерации экземпляров.

### Реализовано

- В DetailView `recurring_tasks.php` появился блок **«История изменений серии»**: ревизия, дата и время, автор изменения, отличия от предыдущей версии (название, ожидаемый продукт, исполнитель, проверяющий, периодичность, дни недели, даты, приоритет, поток и статус).
- Новый атрибут `changedby` фиксирует фактического автора новой ревизии; прежнее поле `creatorid` продолжает означать исходного автора серии. Это устраняет ошибочное приписывание всех последующих действий создателю серии.
- В миграции `2026101631` поле добавляется в существующую таблицу `local_kbacompany_taskrec`. Для исторической ревизии №1 `changedby` заполняется достоверным `creatorid`; для старых ревизий №2+ автор остаётся неизвестным, а не выдумывается.
- Все изменения продолжают записываться отдельными неизменяемыми строками исходной таблицы. Новая отдельная таблица истории **не создаётся**.
- По ссылке **«Задачи по этой версии»** журнал существующих экземпляров фильтруется по `sourcerevision`, уже сохранённой в канонической задаче; это только просмотр, без новых задач и без изменения боевых планов.
- Не показываются необработанные внутренние SHA256 и текст исходных библиотечных метаданных в перечне отличий описания.
- История постраничная (10 ревизий на странице), с прежними company-scoped ACL; задачи в журнале продолжают проходить отдельную проверку доступа.
- Добавлены русские и английские подписи и адаптивное оформление.

### Технические файлы

- `classes/local/recurring_task_service.php`: `compare_revisions()`, `revision_history()`, запись `changedby`, опциональный фильтр `occurrence_journal(..., $revisionfilter)`.
- `recurring_tasks.php`: вывод истории и переходы к экземплярам соответствующей версии.
- `db/install.xml`, `db/upgrade.php`, `version.php`: добавление поля `changedby`, миграция, `2026101631`.
- `lang/ru/local_kbacompany.php`, `lang/en/local_kbacompany.php`, `styles.css`.
- `tests/recurring_task_service_test.php`: unit case для сравнения двух ревизий с редактированием периодичности и цензурированием provenance.

- XML `install.xml` валиден; `changedby` находится только в `local_kbacompany_taskrec`.
- RU/EN: 7 920 уникальных ключей в каждой локализации, одинаковый набор.
- Dynamic PHP smoke: сравнение ревизий, сокрытие технического описания, отсутствие ложных изменений.

**Совместимость:** старые серии и задачи не изменяются; ссылки на экземпляры и закреплённые ревизии сохраняются. Схема БД расширяется ровно одним полем.
