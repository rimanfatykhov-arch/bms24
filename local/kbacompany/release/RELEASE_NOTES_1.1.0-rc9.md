# local_kbacompany 1.1.0-rc9 — Штатное расписание CRUD BMS24

Build: `2026101225`

## Что изменено

- Экран штатного расписания перестроен в единый понятный рабочий редактор BMS24.
- CRUD версии: создание, чтение/реестр, редактирование черновика, безопасная отмена черновика. Утверждённые и архивные версии физически не удаляются и не редактируются.
- Новая версия по умолчанию создаётся копией текущей утверждённой версии.
- Добавлен реестр версий с датой действия, статусом, количеством строк, ставками и месячным ФОТ.
- Параметры версии и все штатные единицы сохраняются одной кнопкой «Сохранить черновик».
- Штатные единицы отображаются полноширинной таблицей и группируются по подразделениям.
- В строке редактируются ставки, оклад от/до и месячный ФОТ.
- Добавлены статусы строки «Без изменений / Добавлено / Изменено».
- Исключение строки сохраняет утверждённую историю; удалённую из черновика строку можно вернуть из блока сравнения.
- Добавление новой штатной единицы сгруппировано по подразделениям и использует канонический справочник должностей.
- Добавлена сводка версии: подразделения, должности, ставки, месячный ФОТ.
- Утверждение остаётся отдельным управленческим действием и не смешивается с обычным сохранением CRUD.
- Схема БД, capabilities и privacy storage не менялись.
- Удалён старый недостижимый фрагмент сравнения из проекции «Штатная расстановка», который ссылался на неинициализированную переменную и мог давать notice в debug-режиме.

## Acceptance focus

1. Открыть действующую утверждённую версию и проверить read-only таблицу.
2. Создать новую версию на основе действующей — все строки должны скопироваться.
3. Изменить ставки/оклад/ФОТ нескольких строк и нажать один раз «Сохранить черновик».
4. Добавить новую должность и убедиться, что она отмечена как «Добавлено».
5. Исключить строку и вернуть её из блока «Изменения относительно предыдущей версии».
6. Проверить сводку по подразделениям/ставкам/ФОТ и реестр версий.
7. Отменить тестовый черновик — утверждённая история должна остаться неизменной.
8. Создать новый черновик и утвердить его; предыдущая версия должна перейти в архив.
