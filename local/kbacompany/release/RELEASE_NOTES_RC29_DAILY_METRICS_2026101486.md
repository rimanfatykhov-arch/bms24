# RC29 build2026101486 — Дневные показатели в недельном боевом плане

- Исправлен фильтр, ранее допускавший только periodtype=weekly. Теперь активная привязка дневной метрики к должности выводится в боевом плане.
- Для дневной метрики сумма значений за 7 календарных дней рассчитывается по каноническим ревизиям statval, отдельно план и факт, без создания второй метрики.
- Количество дней с данными показано; промежуточный итог не выдаётся за итог полной недели. Если факта/плана нет — «—», а не ноль.
- Норма дневной метрики не масштабируется в недельную автоматически. При отсутствии недельного плана состояние «нет данных».
- Создание действий и запись недельного факта отключены для дневного агрегата; дневные значения редактируются из канонической карточки метрики.
- Ограничение: суммирование корректно для аддитивных показателей (выручка), НЕ для процентов, средних значений и коэффициентов; следующим этапом требуется тип агрегации у метрики. Не применять текущий итог как достоверный расчёт долей.
- Проверка PHP, XML, языков, ZIP — статическая; проверка реального Moodle и тесты разных периодов не запускались.
