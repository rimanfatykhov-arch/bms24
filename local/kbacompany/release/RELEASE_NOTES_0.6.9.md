# Release 0.6.9 — Architecture Stabilization / Pre-0.7 Gate

- Adds a deterministic Company-scoped Pre-0.7 platform readiness gate.
- Legacy unmapped companies remain allowed with a warning.
- Cloud entitlement mode requires a usable last-known-good snapshot.
- Platform diagnostics now expose readiness summary and next action.
- No business schema changes; upgrade contains a stabilization savepoint only.
- No automatic Cloud cutover and no new commercial restriction is enabled by this release.
