## Battle Plan carry-forward UX

- The active-week overview now separates already-carried unfinished work from work that still blocks week closure.
- Already-carried canonical task references are shown as completed selections and are not offered for duplicate selection.
- The existing close-readiness wording shows how many unfinished items still need completion or explicit carry-forward.

- The next-plan link and canonical reference-only rollover behavior remain unchanged: tasks are not copied, rescheduled, or given new history.

No DDL, ACL/RBAC, privacy, lifecycle, task-storage, or company-isolation changes.
