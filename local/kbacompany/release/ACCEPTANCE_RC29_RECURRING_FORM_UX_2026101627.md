# Acceptance — BMS24 RC29 build2026101627 — UX регулярных задач

**Перед тестом:** резервная копия плагина и БД, установка новой сборки, очистка кэша Moodle и обновление страницы без кэша браузера.

- [ ] Из боевого плана нажать «Настроить повторение». Форма занимает центральную рабочую область, а не узкую левую колонку.
- [ ] Внутри формы только одна вертикальная колонка; подписи размещены над соответствующими полями.
- [ ] Заголовок «Создать регулярную задачу» отображается один раз над формой; внутри видны «Основные данные» и «Расписание повторения» (без «3.»).
- [ ] Сверху идут название, ожидаемый продукт, исполнитель; ниже периодичность, дата и дни недели.
- [ ] «Дополнительные параметры» раскрываются, содержат описание, принимающего, приоритет, дату окончания, срок и плановые минуты. Закреплённый поток «Регулярная работа» не меняется.
- [ ] «Отмена» и «Сохранить черновик» находятся внизу справа (на телефоне — столбцом).
- [ ] При сохранении новой серии открывается **DetailView** со статусом «Черновик». Не создаются экземпляры, пока серия не активирована.
- [ ] После активации генерируются экземпляры по каноническому расписанию, повторная генерация не дублирует задачи.
- [ ] В утверждённый боевой план новые экземпляры автоматически не добавляются. В черновик — только через действующий механизм синхронизации.
- [ ] Проверить открытие формы редактора, сохранение и ошибки при пустом обязательном поле; введённые данные сохраняются после серверной ошибки.
- [ ] У пользователя без права редактирования кнопки изменения серии скрыты; прямой POST запрещён.
- [ ] Другая компания не может читать, создавать или изменять серию по UUID чужой компании.
- [ ] Проверить русский и английский интерфейс после очистки language cache; нет строк вида `[[recurringtask_...]]`.
- [ ] Проверить экран шириной 390 px, 768 px и 1440 px. Нет горизонтального переполнения и двух колонок в форме.

**При ошибке:** сообщить страницу и шаг, приложить скриншот/trace Moodle. Разделения таблиц или DDL в этой сборке нет.
