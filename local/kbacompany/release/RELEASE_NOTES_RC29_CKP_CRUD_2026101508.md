# BMS24 RC29 build2026101508 — ЦКП CRUD hardening

- Уточнена клиентская обязательность выбора подразделения/должности при переключении организационной принадлежности. Неактивные / чужие записи не подмешиваются в селект при редактировании.
- На сервере пустой UUID выбранного подразделения/должности отклоняется; основной сервис по-прежнему валидирует companyuuid, active=1 и права управления.
- Реестр ЦКП содержит отдельные действия «Просмотр» / «Редактировать» с проверкой manage прав.
- Сохранены UUID, server-generated immutable code, связанные метрики, данные и сценарии создания/редактирования. Нет DDL.
- Архивирование ЦКП **не реализовано**: существующая таблица local_kbacompany_product не имеет архивного статуса; потребуется отдельная миграция и согласование поведения связанных метрик.
- Проверено локально: php -l, ZIP integrity. Live Moodle, DB integration, cross-company RBAC не проверены.
