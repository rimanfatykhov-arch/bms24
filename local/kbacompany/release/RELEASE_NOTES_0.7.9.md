# Release 0.7.9 — Values / Culture / Motivation

- Added a BMS24-standard workspace for company values, culture indicators and motivation factors.
- Added company-scoped culture items with type, description and target level.
- Added employee culture/motivation profile snapshots with current score and manager comment.
- Added visible gap states: aligned / gap / no data.
- Added a People sidebar entry “Values & culture”.
- Added additive schema tables `local_kbacompany_cultitem` and `local_kbacompany_cultscore`.
- Culture/motivation data does not modify competency levels, staffing, Moodle capabilities or learning completion.
- Privacy metadata/export/delete handling extended.
