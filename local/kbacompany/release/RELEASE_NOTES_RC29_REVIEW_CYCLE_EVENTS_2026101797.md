# BMS24 RC29 — build2026101797: журнал циклов согласования

## Результат

- Система теперь записывает отдельные события **отправки плана**, **возврата на доработку**, **утверждения** и **самостоятельного утверждения**.
- События сохраняются под блокировкой плана в одной транзакции с изменением статуса, в отдельном ключе `review_cycle_events` существующего `statepayload`.
- У каждой записи есть тип, ID инициатора, точное время (Unix timestamp) и номер цикла согласования.
- В Боевом плане на вкладках **«История»** и **«Согласование»** отображается журнал, включая время между отправкой и принятым решением, если начало цикла записано.
- Считаются число записанных циклов, число циклов с измеримой длительностью и средняя длительность завершённых циклов; самостоятельное утверждение исключено из среднего.
- **Исторические циклы до обновления не восстанавливаются предположительно.** Если для решения нет зафиксированной отправки, время ожидания показывается как неизвестное.
- Прежние комментарии проверяющего в таблице `local_kbacompany_bplanrev` остаются без изменений. Никаких новых таблиц Moodle и вмешательства в Task Center нет.

## Проверки

- `cli/test_review_cycle_events.php`: точность двух циклов, самостоятельное утверждение, сохранение других полей payload, отсутствие выдуманной истории, отказ от повреждённого JSON.
- `cli/check_review_cycle_contract.py`: проверка регистрации событий на обоих путях утверждения и отправки.
- Штатный release runner, PHP lint, контроль совместимости PHP 8.1, XMLDB и ZIP integrity.

## Приёмка в Moodle 4.1.22 + PHP 8.1.34

1. Установить полный архив; обновить Moodle и очистить кеши.
2. Создать тестовый план, отправить на согласование, вернуть на доработку с причиной, отправить повторно и утвердить.
3. На вкладке **«История»** убедиться, что отражены два цикла, два события отправки, возврат и утверждение с корректными авторами и длительностями.
4. Проверить самостоятельное утверждение отдельно: длительность не должна влиять на среднее.
5. Для старых планов без записанных событий убедиться, что журнал не создаёт ложную историю.
