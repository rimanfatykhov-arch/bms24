# local_kbacompany 0.7.3 — Assessment Engine

- Formal assessment sessions per employee and published position profile.
- Methods: manager observation, interview, test, practical case, evidence review, self-assessment.
- Draft/submitted/approved/rejected lifecycle.
- Competency-level evidence and rationale.
- Only approved assessments project decided levels to Employee Competency Profile.
- Approved assessments are immutable.
- Company scoping is required before reads/writes.
