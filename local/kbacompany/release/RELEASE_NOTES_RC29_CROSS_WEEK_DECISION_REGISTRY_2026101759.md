# BMS24 1.1.0-rc29 build2026101759 — реестр решений за все недели

- Новый экран `battle_plan_decision_registry.php` доступен из быстрой навигации и еженедельной координации.
- Компания, ответственный (выбор по имени), статус, диапазон недель и просроченные решения; пагинация 30 записей.
- Отображается последняя редакция решения на сочетание компания + неделя + исходная задача.
- Фильтры и границы компании применяются в SQL, используется проверка управленческих прав и канонический обзор компании.
- Список только для чтения, каждое решение ссылается на координацию исходной недели.
- Решения без срока не считаются просроченными, завершённые и отменённые исключены из просрочки.
- Без новых таблиц БД, Task Center не меняется.
- Фильтр ответственного показывает имена из сохранённых решений компании.
- QA статическая, работа на реальном Moodle не проверялась.
