# BMS24 RC29 / build2026101632 — сценарии приёмки

## Подготовка

- [ ] Сохранить резервную копию файлов `local/kbacompany` и БД Moodle (важно: база обновлена в RC29/1631).
- [ ] Установить `INSTALL_ME_local_kbacompany_v1.1.0-rc29_build2026101632.zip` в `/local/kbacompany`.
- [ ] Убедиться, что установленная версия `2026101632`, выполнить upgrade Moodle, очистить Moodle caches и Ctrl+F5.

## Проверка BMS App Shell

- [ ] На странице рабочего пространства BMS24 раскрыть **«Управление»**.
- [ ] У пункта **«Мой управленческий цикл»** появилась чёткая иконка чек-листа, выровненная с остальными иконками.
- [ ] В «Управлении» отображается **«Информационный центр»** с иконкой графика.
- [ ] Открыть «Информационный центр»: адрес `/local/kbacompany/information_center.php?uuid=<компания>`, пункт подсвечен, раздел «Управление» раскрыт.
- [ ] На странице «Бизнес-архитектура» прежний переход в «Информационный центр» продолжает работать.
- [ ] На экране 390 px меню открывается без наложения и горизонтального переполнения.

## Права и регрессии

- [ ] Обычный сотрудник с правом просмотра своей компании видит страницу в пределах только своей компании.
- [ ] Уполномоченный руководитель видит новый пункт и остальные управленческие разделы на прежних местах.
- [ ] Пользователь без доступа к другой компании не может открыть её `information_center.php?uuid=...` напрямую.
- [ ] «Мой управленческий цикл», «Обзор управления», «Управленческие циклы», задачи и регулярные задачи открываются по прежним адресам.
- [ ] Иконки не становятся символами `[[...]]`; RU/EN подписи корректны.
- [ ] Проверить, что миграция `changedby` из RC29/1631 завершена на тестовой БД до запуска последующих обновлений.

**Live-проверки не выполнялись в среде подготовки.**
