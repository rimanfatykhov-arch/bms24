## Regular Management Calendar

Adds a manager-only regular-management panel to BMS Calendar with the chain: period launch → meetings → execution control → readiness/weekly acceptance → cycle closure.

The panel is a read model. All lifecycle changes remain in existing canonical Battle Plan and Management Cycle workspaces where permissions and state are revalidated.

No schema, ACL, privacy or canonical domain storage changes.
