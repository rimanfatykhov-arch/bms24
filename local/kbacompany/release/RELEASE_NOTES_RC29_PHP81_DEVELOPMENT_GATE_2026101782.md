# BMS24 1.1.0-rc29 build2026101782

## Изменения
- Добавлен консервативный static gate совместимости кода с синтаксисом PHP 8.1 и 6 fixture-тестов.

- При наличии `PHP81_BIN` gate выполняет настоящий `php -l` на PHP 8.1 для всех PHP-файлов и проверяет точную версию бинарника.
- Добавлен документ `docs/BMS24_DEVELOPMENT_AND_RESEARCH.md` с регламентом фиксации исследований и RC30 backlog.
- Версия/upgrade checkpoint 2026101782, без изменений структуры БД.

## Ограничения
- На машине сборки есть PHP 8.4, а **нативный PHP 8.1 lint не выполнялся**, т.к. нет PHP81_BIN. Статическая проверка не гарантирует совместимость с Moodle API.
- Работа с Moodle 4.1.22 на сервере пользователем подтверждена только для страницы координации, не для всех сценариев.
- Никаких действий с пользовательскими данными при сборке нет.
