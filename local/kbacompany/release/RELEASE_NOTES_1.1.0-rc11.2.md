# local_kbacompany 1.1.0-rc11.2 — Staffing add-unit form UX hotfix

Build: 2026101229

## Fixed
- The staffing plan «Add staffing unit» section no longer compresses labels and the submit button into vertical text.
- The form uses a dedicated responsive grid with sensible widths for position, planned FTE, salary range and monthly payroll.
- On tablet/mobile the grid collapses to two columns and then one column.
- User-facing wording is simplified to «Добавить штатную единицу» and «Добавить в штатное расписание».

## Scope
No DB schema, ACL, privacy or business-domain changes. Live Moodle visual acceptance is still required.
