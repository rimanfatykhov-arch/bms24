# Release Notes — BMS v0.5.2 build 2026091385

## Тренды

В BMS добавлен schema-neutral аналитический слой показателей. Форма тренда не является отдельной статистикой и не заменяет будущий движок управленческих состояний.

Поддерживаются формы:

- Устойчивый рост;
- Устойчивое снижение;
- Без изменения;
- Разнонаправленная динамика;
- Недостаточно данных.

Классификация использует три последних фактических наблюдения и точные сравнения значений. Скрытые процентные пороги отсутствуют.

## Управленческая оценка

Форма тренда оценивается отдельно с учётом направления показателя. Поэтому одинаковый рост может быть улучшением для показателя «больше — лучше» и ухудшением для показателя «меньше — лучше».

## События

Карточка показателя показывает вычисляемые on-read события:

- разворот тренда;
- новый максимум;
- новый минимум;
- выход за норму;
- возврат в норму.

События не сохраняются в БД и не создают строки `statval`.

## Интерфейс

- тренд в Информационном центре;
- тренд и события в карточке показателя;
- тренд в списке всех показателей;
- вкладка «Тренды»;
- фильтры: растущие, снижающиеся, ухудшающиеся, без данных / недостаточно данных.

## Совместимость

- Moodle production target: 4.1.22;
- PHP compatibility target: 7.3;
- schema-neutral upgrade;
- `minval/maxval` сохранены; зарезервированные `minvalue/maxvalue` не возвращаются;
- один canonical Indicator и append-only `statval` сохранены.
