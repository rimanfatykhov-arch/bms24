# BMS24 — RELEASE NOTES
## `local_kbacompany 1.1.0-rc29` — build2026101843

**Название:** Task Deadlines 1.0 — представление задач по срокам.
**Основа:** полный INSTALL ZIP build2026101842. Накопительная сборка, не дифференциальный патч.

### Функциональность

- Новый пункт **«Сроки»** рядом с «Список», «Доска» и «Сводка» на странице `local/kbacompany/tasks.php?uuid=…&display=deadlines`.
- Разделение по календарным группам **«Просрочено»**, **«Сегодня»**, **«Ближайшие 7 дней»** (после сегодняшнего дня до конца семидневного периода), **«Позднее»**, **«Без срока»**. Завершённые и отменённые задачи вынесены в шестую группу «Завершённые и отменённые» и никогда не считаются просроченными.
- Индивидуальные счётчики по всей разрешённой выборке и кликабельный фильтр каждой группы, сохраняющий роли, поиск, источник, Боевой план и другие действующие фильтры.
- Сортировка сроков **на стороне SQL перед пагинацией**: группа → приоритет (высокий, обычный, низкий) → дата → стабильный ID. Дата берётся из `task_service::reporting_dates()` с учётом часового пояса Moodle пользователя и переходов летнего времени.
- Карточки показывают задачу, ожидаемый результат, статус, приоритет, срок, исполнителя и роль пользователя; ссылка открывает действующую карточку задачи.
- Сохранены «Все мои роли» (build1840), конфигурируемая таблица (1841) и массовые действия списка (1842). Просмотр «Сроки» сам по себе не изменяет задачу.
- Чистое HTML-экранирование полей задач. CSS ограничен контейнером `.bms-tui`.

### Безопасность и совместимость

- Списки и агрегаты используют **`task_service::list_conditions()`**, содержащий действующие проверки компании, участия в задаче и полномочий. Новый фильтр `duegroup` применяет только белый список из шести ключей.
- Нет новых веб-хуков, автоматических действий, прямых UPDATE или отдельного хранилища задач.
- **Без изменений схемы БД** (`db/install.xml`, `db/upgrade.php`). Обновлён `version.php` до `2026101843`.
- Канбан с настраиваемыми колонками (1844–1845), MAX и Битрикс24 остаются последующими запланированными этапами; в этом релизе не реализованы.

### Установка

1. Сделать резервную копию Moodle и БД; убедиться, что архив относится к `local_kbacompany` именно этой инсталляции.
2. Установить **`INSTALL_local_kbacompany_1.1.0-rc29_build2026101843.zip`** (полный каталог `kbacompany`), не переименовывая каталог плагина.
3. Открыть `https://edu.kzn.mba/admin/index.php` и завершить процедуру обновления, очистить кэши Moodle.
4. Открыть раздел «Задачи», выбрать «Сроки» и проверить все шесть групп на тестовых задачах.
5. Проверить под обычным сотрудником и руководителем: фильтр «Все мои роли», переходы в карточку, исключение задач другой компании, сохранение фильтров и навигацию по страницам.
6. Проверить, что прежние «Список», «Доска», «Сводка», создание/редактирование задачи, чек-листы, подзадачи, Боевые планы и пакетные действия работают.
7. Отследить журнал PHP/Moodle на ошибки после проверки. При проблемах откатить код и БД до резервной копии.

**Важно:** тестирование на реальном `edu.kzn.mba` и PHP 8.1.34 не выполнялось. Установку и серверную приёмку подтверждает пользователь.
