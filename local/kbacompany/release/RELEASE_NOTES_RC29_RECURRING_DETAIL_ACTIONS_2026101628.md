## Исправления

1. **Готовность к активации.** В черновике или приостановленной серии, если не заполнен ожидаемый продукт, исполнитель или дата начала либо периодичность требует уточнения (`review`), выводится ясное предупреждение со ссылкой на редактирование. Кнопка активации неактивна. Истинная проверка по-прежнему выполняется сервером внутри `recurring_task_service::transition` → `validate_definition(..., true)`; HTML не является механизмом авторизации.
2. **Иерархия действий.** Внизу карточки справа: для неполного черновика — основное «Заполнить данные», вторичное заблокированное «Активировать»; для готового — «Редактировать» и основное «Активировать»; для активного — «Приостановить» и, если предусмотрено, «Создать задачу сегодня». Пользователям без полномочий действия не показываются.
3. **Архивирование с подтверждением.** Ссылка «Архивировать» перемещена в раскрытие «Другие действия». Сначала требуется явный флажок подтверждения, затем отдельная кнопка. При отсутствии `archiveconfirm=1` сервер отклоняет POST до вызова canonical transition; сохраняются `sesskey`, ACL и защита ревизий.
4. **Библиотечное описание.** Идентификатор шаблона, SHA256, исходные метаданные и номер ревизии выведены из основной пользовательской карточки в закрытый по умолчанию блок «Технические сведения» (для имеющих право редактирования). **При EditView метаданные также скрыты из обычного поля «Описание»**; на сохранении они вновь присоединяются к хранимой версии, не пропадают и не мигрируются. Остальные описания остаются неизменными.
5. **Формат дат.** В карточке даты начала/окончания показываются как `ДД.ММ.ГГГГ`.
6. **Предупреждение о потоке.** Когда карточка открыта из раздела «Регулярная работа» боевого плана, но импортированная серия имеет другой поток, показывается предупреждение; старые данные **не исправляются автоматически**. Редактор может проверить и изменить классификацию самостоятельно.
7. **Переводы и стили.** Новые строки в RU/EN и адаптивные CSS-классы для панели действий.
