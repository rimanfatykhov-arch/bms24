# BMS v0.5.8 — Контроль управленческого действия по показателю

Build: **2026091506**

## Цель
Замкнуть недельный управленческий цикл после создания действия из строки показателя Боевого плана, не создавая новый объект статуса действия или результата аналитики.

## Что изменилось
- Связанная canonical Task показывает текущий статус, результат и checklist-прогресс прямо рядом с показателем.
- Checklist-прогресс считается как `выполнено / всего`; если checklist отсутствует, процент не выводится.
- Следующий недельный Боевой план находит governance-event ровно предыдущей недели и показывает связанную canonical Task.
- Факт недели действия сравнивается с фактом следующей недели из append-only `statval`.
- Для направлений `up/down` изменение интерпретируется как улучшение/ухудшение/без изменения; neutral остаётся без искусственной оценки.
- BMS явно не утверждает причинность: это наблюдение «до/после», а не доказательство того, что задача вызвала изменение.
- DOCX-экспорт отражает доступный статус/прогресс/результат задачи и сравнение следующего факта.

## Архитектура
Новых таблиц и источников истины нет. Read-model использует:
`stat/statval/statbind/statnorm/statpolicy/stateevt/task/taskcheck/bplanitem`.

## Совместимость
Moodle 4.1.22 production target; PHP 7.3 compatibility сохраняется.
