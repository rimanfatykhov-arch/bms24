# BMS24 1.1.0-rc29 · build2026101805
## Удаление дублирующей ссылки «Сменить главный инструмент» из верхней панели

**Статус:** кандидат для установки и приёмки. **Живая приёмка на `edu.kzn.mba` не проводилась.**

### Цель

По замечанию пользователя убрать ссылку «Сменить главный инструмент» справа вверху, рядом с учётной записью, **во всех разделах BMS24**. Возможность изменения стартового раздела должна оставаться доступной через левое меню. Не менять логику входа, предпочтения и назначение главного инструмента.

### Изменения

1. `classes/local/bms_page_shell_service.php`: убрана из `topbar.usermenuhtml` дублирующая ссылка в общем BMS Shell (включая «Задачи», Боевые планы и страницы управления). Вывод Moodle user menu сохранён.
2. `bms_workspace.php`: удалена та же ссылка из верхней панели автономного «Рабочего пространства». В боковом меню остался пункт смены инструмента.
3. `templates/bms_workspace_fallback.mustache`: в упрощённом режиме Moodle ссылка перенесена из верхнего блока в боковую навигацию, чтобы функциональность оставалась доступной при отключённом App Shell.
4. `styles.css`: удалены невостребованные стили верхней кнопки, которые больше не используются.
5. `cli/check_main_tool_topbar_cleanup.py`: добавлен контроль отсутствия верхней ссылки в обоих режимах оболочки и наличия ссылки в боковой навигации, а также контроль версии.
6. `cli/check_bms_main_tool_contract.py`, `cli/check_bms_workspace_widgets_contract.py`: сохранены проверки прежних функциональных контрактов без жёсткой привязки к версии прошлой сборки.
7. `cli/build_release.py`: новый контроль включён в обязательную сборку.
8. `version.php`, `db/upgrade.php`: номер версии `2026101805`, штатная отметка обновления без новых таблиц и полей.

### Не изменено

- Адрес `bms_home_preferences.php` и настройки главного инструмента.
- Персональные настройки по пользователю и компании.
- Права доступа, профиль, уведомления и бизнес-логика.
- Компоненты KBA Theme и расположение остальных элементов верхней панели.
- Настройка главного инструмента в содержимом рабочего пространства: не является элементом верхней панели, для неё сохраняется отдельный способ доступа.

### Локальное тестирование

- Запустить `python3 cli/check_main_tool_topbar_cleanup.py` (12 статических проверок).
- Запустить `python3 cli/check_bms_main_tool_contract.py` и `python3 cli/check_bms_workspace_widgets_contract.py`.
- Запустить `python3 cli/build_release.py --summary "RC29/1805 topbar main-tool duplicate removed" --output-dir PATH` — общий regression gate, PHP lint, XMLDB, языковые строки, проверка ZIP + SHA256.
- Локальные проверки не эквивалентны браузерной приёмке на Moodle 4.1 / PHP 8.1.

### Установка

1. Сделать резервную копию плагина `local_kbacompany` и БД Moodle.
2. Установить ZIP как обновление **существующего** плагина (архив содержит корневую папку `kbacompany`).
3. Завершить обновление в административном интерфейсе Moodle до версии `2026101805`.
4. Очистить кэши Moodle; при активном внешнем CDN/браузерном кэше обновить кеш страницы.
5. Проверить на тестовом портале перед установкой в производство.

### Ручная приёмка

1. Открыть «Задачи» (`tasks.php?uuid=...&scope=my`): справа сверху нет ссылки «Сменить главный инструмент», но есть пользовательское меню.
2. На той же странице в левом меню есть пункт «Сменить главный инструмент» и он ведёт на настройки.
3. Повторить на «Рабочем пространстве», «Боевом плане», «Управлении».
4. Выбрать другой главный инструмент через левое меню, обновить страницу и проверить сохранение выбора.
5. Проверить, что логотип BMS24 открывает персональный главный инструмент.
6. Проверить интерфейс на узком экране: верхняя панель не оставляет пустого места, меню пользователя открывается.
7. При стандартной (fallback) теме Moodle проверить, что ссылка размещена в боковой навигации, а не в верхнем блоке.
8. Проверить под обычным сотрудником и руководителем: настройки и доступ к компаниям не изменились.
