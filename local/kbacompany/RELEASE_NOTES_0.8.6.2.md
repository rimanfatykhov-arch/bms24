# BMS 0.8.6.2 — Battle Plan Approval

- Added structured review of submitted Battle Plans.
- Reviewer sees tasks, expected products, plan/fact time and canonical weekly indicators/quotas.
- Reviewer can approve or return the plan for correction.
- Correction may target selected Battle Plan task references or the plan as a whole.
- Review decisions are append-only and company-scoped.
- Approval activates the canonical Battle Plan; correction returns the same plan to draft.
- No parallel task/KPI/plan engine.
