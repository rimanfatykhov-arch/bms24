# local_kbacompany 1.1.0-rc7 — Метрики 2.0

## Изменения
- Пользовательская терминология раздела переведена с «Показатели» на «Метрики» без переименования технических таблиц/API.
- Информационный центр показывает только метрики с явной отметкой «Главная метрика компании».
- Отметка хранится через существующую версионную company-binding (`local_kbacompany_statbind.isprimary`), без новой таблицы и без копии метрики.
- В «Все метрики» добавлен признак главной метрики и полноценное редактирование определения: код, название, единица, периодичность, направление, продукт/ЦКП, описание, источник, конфигурация источника, агрегация.
- Добавлена навигация карточки: Основное / План и нормы / Факты / Привязки / Формула и источник / История.
- Обновление определения сохраняет UUID метрики и append-only историю план/факт.

## Совместимость
- Схема БД не менялась.
- Внутренние имена `stat`, `indicator_*`, таблицы и API сохранены для обратной совместимости.
