# BMS 0.6.9.10 — Проверка бизнес-модели и реестр разрывов

Build: `2026092204`

- Добавлена проверка точной редакции целевой бизнес-модели по пяти контурам: рынок, клиент, экономика, ресурсы, требования собственника.
- Экономика может быть подтверждена только опубликованным финансовым сценарием, закреплённым за той же редакцией бизнес-модели.
- Покрытие требований собственника теперь считается только по записям «Как должно быть».
- Добавлен versioned canonical Реестр разрывов со Stable Code `GAP-xxxx`.
- Разрыв связывает точные записи «Как есть» и «Как должно быть» одного блока; GAP не превращается автоматически в проект.
- Разрыв может ссылаться на существующий BMS Indicator как показатель результата.
- Добавлены таблицы `bmcval`, `bmcgap`, `bmcgapreq`; Company isolation и revision pinning обязательны.
- Privacy provider дополнен для новых actor fields и содержимого validation/GAP records.
- Не добавлены новые capabilities или external services.
