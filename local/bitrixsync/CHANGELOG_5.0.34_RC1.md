# KBA Connect v5.0.34 RC1 — Changelog

- Pairing is now the primary Corporate Dashboard connection status.
- Removed duplicate Dashboard detected / Production Dashboard indicators from normal UI.
- Legacy Corporate API URL, API Key and manual Bearer token moved under Advanced / Legacy settings.
- Bitrix24 schema health no longer uses `profile`; it checks `crm.contact.userfield.list`.
- Corporate Role Schema uses paired API 1.11 as the preferred compatibility contract.
- Existing pairing storage, schema provisioning and legacy sync remain backward compatible.
