# KBA Corporate Dashboard 0.19.3.5

Build: `2026090233`

- Added filters to the company administration page.
- Administrators can select one company, filter active/inactive companies and search by name, code or Bitrix24 ID.
- Added a visible «shown of total» counter and one-click filter reset.
- The company table now scrolls inside its own container on narrow screens.

This release has no database schema changes and upgrades directly from 0.19.3.4.
