# KBA Corporate Dashboard 0.19.3

Build: `2026090228`

- Added monthly before/after development dynamics for 3, 6, 12 months or all time.
- The baseline comes from the level captured when the individual development plan was created.
- The final level comes only from a confirmed assessment in the follow-up audit linked to that plan.
- Newly assessed competencies are counted but excluded from average growth because no baseline exists.
- The filtered timeline is included in the CSV export.

This release has no database schema changes and upgrades directly from 0.19.2.
