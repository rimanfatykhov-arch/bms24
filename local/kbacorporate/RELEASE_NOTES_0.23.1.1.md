# KBA Corporate Dashboard 0.23.1.1

Build: `2026090255`

This hotfix keeps “BMS implementation” visible in the permanent Moodle top bar for administrators and managers who can access several companies. If the current page does not provide a company context, the link opens a tenant-safe company chooser. With one available company, the user is redirected directly to its implementation workspace.

Direct package selection introduced in v0.23.1 is unchanged. Existing audits, BMS Index history, requests, implementation programs, tariff settings and Bitrix24 integration settings are preserved.

Upgrade over v0.23.1 without uninstalling the plugin. No schema migration is required.
