# KBA Corporate Dashboard 0.24.1

New BMS implementation requests now produce immediate Moodle notifications.

## Customer

- Receives confirmation with the company, selected package and submission date.
- Can open the BMS implementation workspace directly from the notification.
- Sees the request submission date in the saved request card.

## Administrator

- Users authorised to manage implementation programs receive a new-request alert.
- The alert opens the correct client workspace, where the request and active-client banner are visible.

Popup and email delivery follow each user’s Moodle notification preferences. A delivery failure is logged but does not roll back the saved request.
