# KBA Corporate Dashboard 0.22.2.1

Build: `2026090251`

This corrective release serializes nested Bitrix24 REST parameters as bracketed form fields. It fixes `Parameter 'order' must be array` on the stage selector and applies the same transport rule to filters and CRM deal fields.

Install the full ZIP over v0.22.2 without uninstalling the plugin. Return to the Bitrix24 pipeline selector, choose the pipeline and press “Load stages for selected pipeline”.
