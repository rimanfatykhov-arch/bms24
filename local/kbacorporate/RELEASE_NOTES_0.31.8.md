# KBA Corporate Dashboard v0.31.8
## Прогресс учебного плана и повторная оценка

Дата: 8 сентября 2026 года  
Тип изменения: MINOR  
Build: `2026090804`

## Назначение

Добавить управляемый контроль выполнения уже созданного учебного плана:

`план KBA → рекомендуемые курсы → выполнение действий → подтверждённый уровень компетенции → повторная оценка → закрытие разрыва`.

## Добавлено

- отдельная страница «Прогресс учебного плана»;
- единая таблица по каждому пункту плана: компетенция, курс, прогресс курса, статус действия, срок, исходный/текущий/целевой уровень и следующий шаг;
- средний прогресс по назначенным курсам;
- показатели выполнения действий плана, покрытия оценкой и достижения целевых уровней;
- подсчёт просроченных действий и пунктов, требующих повторной оценки;
- фильтры: требуют внимания, просроченные, нуждающиеся в повторной оценке, в процессе, завершённые, без курса;
- ручная синхронизация завершённых курсов с действиями активного плана;
- переход к итоговой повторной оценке компетенций после завершения плана;
- прямые ссылки на план KBA, стандартный учебный план Moodle, разрывы сотрудника и список планов;
- ссылка на прогресс из карточки плана, списка планов и итогового экрана создания плана.

## Принцип данных

- завершение курса является доказательством прохождения обучения;
- завершение курса может завершить действие плана после синхронизации;
- завершение курса не изменяет подтверждённый уровень компетенции;
- разрыв считается закрытым только после новой подтверждённой оценки в Moodle;
- отсутствие оценки не интерпретируется как уровень 0.

## Безопасность

- страница прогресса по умолчанию только читает данные;
- синхронизация использует существующий идемпотентный механизм `sync_course_completions()`;
- повторная оценка создаётся только для завершённого плана и только пользователем с соответствующими правами;
- схема базы данных не меняется;
- автоматическое зачисление на курсы не выполняется;
- destructive migration отсутствует.

## Новая точка входа

`/local/kbacorporate/study_plan_progress.php?id=<KBA_PLAN_ID>`

## Известные ограничения

- прогресс курса зависит от включённого и корректно настроенного completion tracking Moodle;
- курс без зачисления отображается как «Не зачислен»;
- назначение/зачисление на рекомендуемые курсы будет реализовано отдельным релизом v0.31.9;
- runtime-проверка должна быть выполнена на пилотном Moodle 4.0.
