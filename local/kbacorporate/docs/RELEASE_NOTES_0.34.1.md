# KBA Corporate Dashboard v0.34.1 — Панель экономических показателей аудита

- Moodle component: `local_kbacorporate`
- Numeric build: `2026090904`
- Minimum Moodle: 4.0
- Status: BETA / подготовлен к пилотной runtime-проверке
- Upgrade path: in-place from `0.34.0.2`
- Schema impact: none

## Назначение

Релиз превращает реестр экономических показателей в наглядную управленческую панель. Собственник и руководитель получают единый экран с текущими KPI, динамикой по периодам, отклонениями от плана, прогнозом и экономическим контекстом выбранного аудита BMS.

Цепочка релиза:

`компания → экономические значения → KPI-карточки → графики динамики → факт / план / прогноз → контекст аудита`.

Панель работает только на чтение и не изменяет значения реестра, аудиты или действия внедрения.

## Основные возможности

### KPI-карточки

Для каждого выбранного показателя выводятся:

- последнее фактическое значение;
- период значения;
- изменение к предыдущему фактическому периоду;
- план того же периода;
- отклонение факта от плана;
- прогноз того же периода;
- источник и статус подтверждения;
- дата последнего обновления.

Интерпретация изменения учитывает направление показателя: для `up` рост положителен, для `down` положительным считается снижение, для `target` изменение отображается нейтрально без отдельной цели.

### Графики

Для каждого показателя формируются:

- линейный график фактических значений, до 18 последних точек;
- столбиковое сравнение `Факт / План / Прогноз` для текущего периода.

Используется стандартный механизм диаграмм Moodle. Внешние CDN и сторонние JavaScript-библиотеки не подключаются.

Денежная динамика с разными валютами не объединяется в один график. Пользователь получает явное предупреждение о несопоставимости.

### Контекст аудита BMS

При открытии панели из аудита показываются:

- значения, прямо связанные с выбранным аудитом;
- ближайший предыдущий подтверждённый аудит того же инструмента;
- значение до и после;
- абсолютное и процентное изменение;
- оценка направления динамики;
- переход к полному сравнению аудитов.

Если аудит старше стандартного периода панели и пользователь не задавал даты вручную, его связанные значения включаются в видимый диапазон автоматически.

### Фильтры

Доступны:

- период с / по;
- категория показателя;
- периодичность;
- контекст аудита;
- выбор до 8 показателей;
- только подтверждённые значения.

При первом открытии система выбирает до 6 приоритетных KPI с данными. Явный выбор пользователя сохраняет порядок и ограничивается 8 показателями, чтобы страница оставалась читаемой.

### CSV-экспорт

Экспорт включает значения выбранных показателей с учётом фильтров панели: период, сценарий, источник, подтверждение и связь с аудитом. Текстовые значения защищаются существующим механизмом от интерпретации как формул в электронных таблицах.

## Точки входа

- компактное меню BMS: **Экономика**;
- реестр экономических показателей;
- карточка аудита;
- сравнение аудитов.

Основной URL:

`/local/kbacorporate/economic_dashboard.php?companyid=<ID>`

Контекст аудита:

`/local/kbacorporate/economic_dashboard.php?companyid=<ID>&auditid=<ID_АУДИТА>`

## Права и изоляция

- требуется `local/kbacorporate:vieweconomicindicators`;
- доступ к компании проверяется до построения модели;
- кнопка добавления значения доступна только с `manageeconomicindicators`;
- переданный `auditid` должен принадлежать той же компании;
- данные другой компании через фильтры и экспорт не раскрываются.

## Изменение базы данных

Схема БД не меняется. Добавляется upgrade savepoint `2026090904`.

## Что не входит

- прогнозирование значений алгоритмом;
- конвертация валют;
- доказательство причинной связи между внедрением и экономическим результатом;
- редактирование значений прямо на графике;
- произвольный пользовательский конструктор расположения виджетов;
- управленческие панели по ролям — это задача `v0.34.3`.

## Резервное копирование и откат

Перед обновлением рекомендуется стандартная резервная копия БД и каталога плагина. Поскольку схема не меняется, откат выполняется восстановлением файлов `v0.34.0.2` и очисткой кэшей Moodle.
