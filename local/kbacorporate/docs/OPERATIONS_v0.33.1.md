# OPERATIONS — Implementation evidence v0.33.1

## Assignee procedure

1. Start the implementation task.
2. Open «Доказательства внедрения».
3. Describe the actual result, add a URL/files and confirm relevance.
4. Submit for review.
5. If returned, read the reviewer comment and submit the next version.

## Reviewer procedure

1. Open a task in status «На проверке».
2. Open the evidence workspace.
3. Compare the version with the expected task result.
4. Accept, or return it with mandatory feedback.

## Operational controls

- only one version can be pending at a time;
- accepted/rejected versions remain visible;
- task status is locked in the generic editor after versioning starts;
- completion of a task does not update the BMS criterion score automatically;
- monitor missing tables through Integration Health Center.

## Retention

Evidence and logs are retained with the implementation task until company deletion or privacy processing. Files follow the corresponding evidence record.
