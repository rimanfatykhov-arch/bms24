# PRODUCT PASSPORT — v0.33.4

## Продукт

KBA Corporate Dashboard / модуль «Реестр экономических показателей».

## Назначение

Единый каталог и история экономических показателей корпоративного клиента для связи с аудитами BMS, будущих графиков, сравнения «до / после» и ERP-обмена.

## Пользователи

- собственник и генеральный директор;
- финансовый руководитель;
- куратор внедрения;
- корпоративный менеджер KBA;
- интеграционная служба ERP/API.

## Основной результат

Проверяемая структура `показатель → период → сценарий → значение → источник → аудит`, без привязки внешних систем к внутренним DB id.

## Границы релиза

Релиз хранит и показывает данные. Графики, причинная аналитика и публичный ERP endpoint не входят.
