# KBA Corporate Dashboard v0.34.0 — Сравнение аудитов «до / после»

- Moodle component: `local_kbacorporate`
- Numeric build: `2026090901`
- Minimum Moodle: 4.0
- Status: BETA / подготовлен к пилотной runtime-проверке
- Upgrade path: in-place from `0.33.4`
- Schema impact: none

## Назначение

Релиз добавляет сопоставление двух подтверждённых аудитов одного инструмента BMS. Руководитель и куратор получают единый ответ на вопросы:

`что изменилось в зрелости → какие риски появились или сняты → какие действия выполнялись → какие экономические значения связаны с аудитами`.

Сравнение является аналитической проекцией и не изменяет исходные аудиты, задачи, доказательства или экономические данные.

## Основные возможности

### Выбор пары аудитов

- выбор компании;
- выбор BMS-инструмента с двумя и более подтверждёнными аудитами;
- выбор точки «до» и точки «после»;
- автоматический выбор двух последних подтверждённых аудитов;
- автоматический подбор ближайшего предыдущего аудита при открытии сравнения из карточки аудита;
- защита от сравнения аудитов разных компаний, разных инструментов и неподтверждённых аудитов;
- нормализация обратного порядка дат.

### Сравнение BMS Index и покрытия

Показываются:

- BMS Index до и после;
- абсолютное изменение индекса;
- покрытие оценкой;
- число сопоставимых критериев;
- число разрывов до цели до и после.

### Сравнение критериев

Критерии сопоставляются по сохранённому стабильному коду, а не по внутреннему ID текущей версии инструмента. Это позволяет сравнивать аудиты, созданные по разным опубликованным версиям BMS-инструмента.

Для каждого критерия рассчитываются:

- фактическая оценка до и после;
- нормализованная оценка в процентах шкалы;
- изменение в процентных пунктах;
- разрыв до целевого уровня до и после;
- изменение разрыва;
- состояние зоны риска;
- связанные действия внедрения;
- принятые доказательства между аудитами.

Поддерживаемые состояния изменения:

- улучшение;
- ухудшение;
- без изменений;
- впервые оценено;
- оценка потеряна;
- новый критерий;
- исключённый критерий;
- не оценено в обоих аудитах.

### Сравнение разделов BMS

По каждому разделу показываются:

- средняя нормализованная оценка до и после;
- изменение в процентных пунктах;
- количество улучшившихся, ухудшившихся и неизменившихся критериев;
- новые, снятые и сохраняющиеся зоны риска;
- итоговый аналитический статус раздела.

### Контекст действий внедрения

В отдельной таблице выводятся действия, созданные из критериев аудита «до»:

- критерий;
- название действия;
- ответственный;
- приоритет;
- статус;
- срок;
- дата завершения;
- количество принятых доказательств между двумя аудитами.

Действия и доказательства представлены как контекст. Система не утверждает автоматическую причинно-следственную связь между действием и ростом оценки.

### Экономические показатели

При наличии права просмотра экономики сравниваются последние фактические значения каждого показателя, прямо связанные с выбранными аудитами:

- значение до;
- значение после;
- абсолютное изменение;
- процент изменения;
- оценка динамики с учётом направления показателя.

Для показателей с направлением `target` изменение показывается как нейтральное, поскольку без отдельного целевого значения нельзя корректно определить положительность динамики. Денежные значения в разных валютах не сопоставляются.

Графики и полноценная экономическая панель остаются задачей `v0.34.1`.

### Фильтры и CSV

Добавлены фильтры по:

- статусу изменения;
- состоянию риска;
- разделу BMS;
- коду и названию критерия.

CSV включает отфильтрованные критерии, сводку по разделам и доступное пользователю сравнение экономических показателей. Текстовые значения защищены от formula injection.

## Точки входа

- компактное меню рабочего пространства BMS;
- список аудитов;
- карточка подтверждённого аудита;
- экран прогресса внедрения по разделам.

Основной URL:

`/local/kbacorporate/implementation_audit_comparison.php?companyid=<ID>`

Глубокая ссылка из аудита:

`/local/kbacorporate/implementation_audit_comparison.php?companyid=<ID>&auditid=<ID_АУДИТА>`

## Права и изоляция

- менеджеры с `manageimplementationaudits` видят доступные им компании;
- назначенные кураторы видят только компании своих действующих программ внедрения;
- экономические значения выводятся только при наличии `vieweconomicindicators`;
- сравнение не раскрывает данные другой компании через переданные ID.

## Изменение базы данных

Схема базы данных не меняется. Добавляется только upgrade savepoint `2026090901`.

## Что не входит

- графики динамики по всей истории;
- прогноз BMS Index;
- доказательство причинности;
- автоматическая генерация управленческих выводов;
- сравнение неподтверждённых черновиков;
- сравнение разных инструментов;
- автоматическое изменение аудитов или действий.

## Резервное копирование и откат

Перед обновлением по стандарту проекта рекомендуется резервная копия БД и каталога плагина. Поскольку схема БД не меняется, откат выполняется заменой файлов на `v0.33.4` и очисткой кэшей Moodle.
