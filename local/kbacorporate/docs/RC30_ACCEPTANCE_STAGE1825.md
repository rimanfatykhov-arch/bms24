# Матрица допуска RC30 — Corporate ↔ BMS24 (1825)

| Блок | Тест | Метод | Текущий статус |
|---|---|---|---|
| Установочный ZIP | Целостность, корневой каталог, версия | Локальная сборка | Выполняется локально |
| PHP | Синтаксис всех файлов на PHP CLI 8.4 | Локальный lint | Выполняется локально |
| API Corporate | Доступность версии 1.26 | CLI на Moodle | Требуется сервер |
| Куратор | Реальное назначение и доступ по company ID | CLI + браузер | Требуется сервер |
| Многокомпанейность | A→B, B→A и подмена task ID | CLI + браузер | Требуется сервер |
| BMS24 | UUID компании, корпоративный ID и активный источник | CLI с `--bmsuuid` | Требуется сервер |
| Боевой план | Одно включение, без копирования, корректная неделя | Браузер | Требуется сервер |
| Приёмка | submitted → rejected → submitted → accepted | Браузер | Требуется сервер |
| Канбан | Края пагинации и полные счётчики | CLI + браузер | Требуется сервер |
| Производительность | Медиана, p95, SQL count, память | CLI + profiler | Требуется сервер |
| SQL | EXPLAIN на MySQL 5.7, отсутствие критичных full scan | DBA на стенде | Требуется сервер |
| Совместимость | Moodle 4.1.22, PHP 8.1.34 | Стенд | Требуется сервер |

**Gate:** RC30 остаётся кандидатом, пока серверные пункты не подтверждены воспроизводимым отчётом. `SKIP` не является `PASS`. Не считать неизвестные результаты нулями.
