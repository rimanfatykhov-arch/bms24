# Security and Privacy v0.34.0

- Login is required.
- Company access is checked before audit IDs are used.
- Both audits must belong to the selected company and the same tool.
- Curator access is constrained by assigned implementation programs.
- Economic values require `vieweconomicindicators`.
- The page is read-only and introduces no new personal-data store.
- CSV content reuses the economic registry formula-injection protection.
