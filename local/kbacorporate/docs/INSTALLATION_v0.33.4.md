# INSTALLATION — v0.33.4

## Перед установкой

1. Создать резервную копию БД.
2. Скопировать текущий каталог `local/kbacorporate`.
3. Зафиксировать резервную копию `moodledata`.
4. Проверить, что текущий build не выше `2026090815`.

## Установка

Установить полный ZIP через стандартное обновление Moodle. Ожидаемый build после upgrade: `2026090815`.

## После установки

1. Очистить кэши Moodle.
2. Проверить наличие 3 новых таблиц.
3. Открыть «Экономические показатели» для тестовой компании.
4. Убедиться, что системный каталог заполнен.
5. Проверить migrated values из старых economic snapshots.

## Откат

Для полного отката восстановить БД и файлы из резервной копии. Простая замена каталога плагина не удаляет новые таблицы.
