# Installation v0.34.0

1. Back up the database and `local/kbacorporate`.
2. Install the ZIP through Moodle plugin administration or replace the plugin directory.
3. Complete the Moodle upgrade to build `2026090901`.
4. Purge all caches.
5. Open `/local/kbacorporate/implementation_audit_comparison.php?companyid=<ID>`.

No database tables or fields are added.
