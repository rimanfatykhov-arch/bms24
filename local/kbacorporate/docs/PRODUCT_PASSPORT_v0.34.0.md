# Product Passport v0.34.0

## Module

Сравнение подтверждённых BMS-аудитов «до / после».

## Users

Собственник, генеральный директор, куратор внедрения, уполномоченный менеджер BMS.

## Business outcome

Показывает изменение зрелости системы управления между двумя зафиксированными состояниями, контекст действий внедрения и связанные экономические значения.

## Inputs

- два подтверждённых аудита одной компании и одного инструмента;
- snapshot-критерии аудитов;
- действия, созданные из аудита «до»;
- принятые доказательства между датами;
- фактические economic values, связанные с аудитами.

## Outputs

- BMS Index delta;
- section and criterion changes;
- risk transitions;
- gap transitions;
- action/evidence context;
- economic value comparison;
- CSV export.

## Boundaries

Модуль не изменяет данные и не доказывает причинность.
