# Operations v0.34.0

## Preconditions

- at least two confirmed audits for the same company/tool;
- access to the company;
- `vieweconomicindicators` for the economic section.

## Routine use

1. Select company and tool.
2. Select before and after audits.
3. Review index and section changes.
4. Filter criterion changes and risks.
5. Review actions/evidence as context.
6. Export CSV when required.

## Interpretation rule

Actions and evidence are contextual, not automatic causal attribution.
