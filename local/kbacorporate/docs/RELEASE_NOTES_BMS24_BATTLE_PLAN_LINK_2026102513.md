# local_kbacorporate 0.40.4 — переход к Боевому плану BMS24

Версия `2026102513`, добавлена навигационная кнопка в карточку задачи внедрения.

- Кнопка «Добавить в Боевой план» доступна только исполнителю задачи и только когда публичный API подтверждает attachable (оплаченная активная программа, статусы planned/inprogress) и установлен новый BMS-маршрут.
- Переход GET без изменения данных Corporate. BMS24 независимо проверяет company, источник и пользователя и выполняет добавление только после POST/sesskey.
- Нет изменений таблиц, дискуссий, статусов, приёмки результатов; публичный API 1.22 сохранён.
- Файлы: `implementation_task.php`, `lang/ru/...`, `lang/en/...`, `version.php`, `db/upgrade.php`, этот документ.
- Требуется BMS24 `2026101815` для полного сценария. При недоступности BMS кнопка скрыта.
- PHPUnit/E2E на сервере не запускались, до эксплуатации проверить два пользовательских контекста и разграничение компаний.
