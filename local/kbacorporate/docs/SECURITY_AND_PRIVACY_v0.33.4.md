# SECURITY AND PRIVACY — v0.33.4

## Права

- просмотр: `local/kbacorporate:vieweconomicindicators`;
- изменение: `local/kbacorporate:manageeconomicindicators`;
- дополнительно обязательна существующая проверка company access.

## Защита tenant scope

- indicator компании доступен только той же компании;
- глобальный indicator доступен только как shared definition;
- value всегда фильтруется по `companyid`;
- audit link проверяется по `audit.companyid`;
- CSV использует те же проверки, что экран.

## Персональные данные

Идентификаторы авторов, редакторов и проверяющих включены в Privacy API. При удалении данных пользователя ссылки на него анонимизируются, включая идентификаторы проверяющих внутри снимков `oldjson/newjson`, а экономическая история компании сохраняется.

## Риски

Экономические показатели являются конфиденциальными корпоративными данными. Capabilities не следует назначать обычным пользователям без отдельного решения заказчика.

## CSV

Текстовые поля защищены от formula injection. Экспорт не должен публиковаться по внешней ссылке без дополнительной авторизации.
