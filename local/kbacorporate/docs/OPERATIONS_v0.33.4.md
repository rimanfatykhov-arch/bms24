# OPERATIONS — v0.33.4

## Регулярная работа

1. Выбрать компанию.
2. Открыть «Экономические показатели».
3. Выбрать показатель и сценарий: факт, план или прогноз.
4. Указать период и значение.
5. Зафиксировать источник и комментарий.
6. При необходимости связать значение с аудитом BMS.
7. Подтвердить проверенное значение.

## Управление каталогом

Системные показатели не редактируются. Отраслевой показатель создаётся с уникальным стабильным кодом компании. Устаревшие показатели архивируются.

## Контроль качества

- не использовать один код для разных смыслов;
- не выбирать ERP как источник для неподтверждённого ручного расчёта без комментария;
- не заменять факт планом;
- перед корректировкой исторического значения проверить журнал изменений;
- регулярно экспортировать контрольный CSV.
