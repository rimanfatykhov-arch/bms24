# KBA Corporate Dashboard v0.32.2
## Повторная оценка компетенций после завершения плана развития

Дата: 8 сентября 2026 года  
Тип изменения: MINOR  
Build: `2026090807`

## Назначение

Завершить цикл развития сотрудника управляемой повторной оценкой компетенций:

`исходный уровень → план развития → обучение → новые доказательства → предложение уровня → подтверждение → результат до/после → оставшийся разрыв`.

Релиз не принимает завершение курса за подтверждённое изменение уровня. Любой новый уровень должен быть явно подтверждён пользователем с правом оценки компетенций Moodle.

## Добавлено

- отдельный экран подготовки повторной оценки по завершённому плану развития;
- обязательный предпросмотр состава компетенций, исходных уровней, целей и результатов обучения;
- отдельное рабочее пространство повторной оценки;
- неизменяемый снимок исходного уровня и цели из пункта плана развития;
- фильтрация доказательств по контрольной дате начала цикла развития;
- сбор новых доказательств Moodle без автоматического подтверждения уровня;
- ручное внесение повторной оценки для отсутствующего или отклонённого результата;
- подтверждение или отклонение отдельного предложения;
- массовое подтверждение ожидающих предложений при наличии права Moodle на оценку компетенции;
- сравнение «до обучения / после обучения / целевой уровень»;
- расчёт изменения уровня и оставшегося разрыва;
- состояния результата: не оценено, ожидает подтверждения, отклонено, оценено впервые, уровень вырос, без изменений, снизился, цель достигнута;
- переход к оставшимся разрывам и следующему учебному плану;
- прямые переходы из плана развития, прогресса учебного плана и списка аудитов.

## Правила источника истины

- исходный уровень фиксируется из пункта завершённого плана развития;
- старый текущий уровень Moodle, существовавший до начала цикла развития, не принимается как повторная оценка;
- новый текущий уровень или evidence после контрольной даты может создать только предложение со статусом ожидания подтверждения;
- завершение курса является доказательством обучения, но не подтверждением уровня;
- изменение подтверждённого уровня выполняется только через Moodle Competencies API;
- отсутствие оценки не преобразуется в уровень `0`.

## Идемпотентность и безопасность

- повторный запуск для одного завершённого плана возвращает уже созданную повторную оценку;
- подтверждённые и отклонённые пункты не перезаписываются автоматическим обновлением доказательств;
- ручное повторное внесение отклонённого результата повторно открывает оценку;
- произвольную компетенцию нельзя добавить в повторную оценку через подмену POST-параметра;
- данные других компаний недоступны благодаря существующей проверке полного доступа к компании;
- схема базы данных не меняется;
- destructive migration отсутствует.

## Новые точки входа

- `/local/kbacorporate/competency_reassessment_start.php?planid=<PLAN_ID>`
- `/local/kbacorporate/competency_reassessment.php?id=<AUDIT_ID>`

## Изменённые точки входа

- завершённый план развития предлагает подготовить или открыть повторную оценку;
- страница прогресса учебного плана предлагает тот же управляемый переход;
- записи аудита типа `development` открываются в новом рабочем пространстве;
- техническая карточка аудита сохраняется и содержит ссылку на рабочее пространство повторной оценки.

## Известные ограничения

- автоматическая интерпретация свободного текста и файлов доказательств в уровень компетенции не выполняется;
- массовое подтверждение подтверждает все ожидающие предложения, поэтому ответственный должен сначала проверить таблицу;
- полнота автоматически собранных доказательств зависит от данных Moodle Competencies и Course Competencies;
- повторные оценки, созданные до v0.32.2, могли использовать прежнюю логику формирования; релиз не переписывает их историю автоматически;
- runtime-проверка Moodle API, SQL, прав доступа и workflow выполняется на пилотном сервере.

## Upgrade

Обновление выполняется поверх `v0.32.1`. База данных не меняется; `db/upgrade.php` фиксирует savepoint `2026090807`.
