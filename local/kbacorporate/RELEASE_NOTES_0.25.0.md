# KBA Corporate Dashboard 0.25.0

Implementation tasks are now working spaces rather than rows in a table.

## Task workspace

- Open a task by clicking its title or **Open task**.
- The direct URL contains only the stable task ID and can be shared with authorised participants.
- The page shows the current client, status, owner, priority, deadline, audit criterion and expected result.
- Administrators can continue to the existing task editor.

## Discussion

- The assigned employee, authorised company managers and curator can follow the work through chronological messages.
- Participants receive Moodle popup/email notifications with a direct task link.
- Discussion messages are communication only. They do not replace the task’s official evidence files or affect assessment.
