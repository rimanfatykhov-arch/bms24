# KBA Corporate Dashboard v0.31.6
## Предпросмотр учебного плана по разрывам компетенций

Дата: 8 сентября 2026 года  
Тип изменения: MINOR  
Build: `2026090802`

## Назначение

Добавить безопасный этап предпросмотра перед созданием или обновлением учебного плана сотрудника на основе подтверждённых разрывов компетенций.

## Добавлено

- выбор конкретных подтверждённых разрывов, которые попадут в учебный план;
- явное исключение неоценённых компетенций и результатов, ожидающих подтверждения;
- этапы и рекомендуемые сроки:
  - этап 1 — критические компетенции, до 30 дней;
  - этап 2 — основные компетенции, до 60 дней;
  - этап 3 — дополнительные компетенции, до 90 дней;
- отображение обязательности компетенции;
- предупреждения для обязательных компетенций без курса;
- отображение прогресса по рекомендованному курсу, если он доступен;
- отдельные статусы готовности предпросмотра;
- сохранение существующих сроков и ранее выбранного курса в черновике;
- результат применения теперь показывает число выбранных и пропущенных подтверждённых разрывов.

## Изменено

- `preview_gap_learning_plan()` использует подтверждённую проекцию `employee_gap`;
- неизвестный текущий уровень больше не может автоматически попасть в учебный план;
- `build_gap_learning_plan()` принимает необязательный перечень выбранных компетенций;
- автоматическое формирование обрабатывает только подтверждённые положительные разрывы.

## Безопасность данных

- существующие пункты учебного плана не удаляются;
- пункты вне текущего перечня разрывов сохраняются;
- активный или отправленный на согласование план остаётся заблокированным для автоматической пересборки;
- схема базы данных не меняется;
- destructive migration отсутствует.
