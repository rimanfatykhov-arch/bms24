# KBA Corporate Dashboard 0.18.2.2

Build: `2026090215`

## Competency map filters

- “Confirmed gap” now means only an assessed competency with a positive gap.
- “Not assessed” remains a separate status.
- “Requires attention” includes every row marked by the competency profile rules.
- Role, framework and status selectors apply automatically.
- Search is applied by the “Apply” button.
- Active filters are displayed above the summary cards.
- “Reset” returns to the unfiltered company map.

No database schema changes are introduced in this release.
