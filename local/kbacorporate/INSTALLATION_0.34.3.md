# Installation 0.34.3

1. Сделайте резервную копию файлов Moodle и базы данных.
2. Откройте «Администрирование сайта → Плагины → Установка плагинов».
3. Загрузите полный ZIP релиза.
4. Проверьте компонент `local_kbacorporate` и build `2026091001`.
5. Завершите стандартное обновление Moodle.
6. Очистите кэши Moodle.
7. Откройте «Внедрение BMS → Панели» и проверьте доступ каждой роли.

ZIP содержит один корневой каталог `kbacorporate/`. Изменений схемы данных и миграций данных в этом релизе нет.
