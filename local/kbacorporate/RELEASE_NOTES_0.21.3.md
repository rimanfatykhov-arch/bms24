# KBA Corporate Dashboard 0.21.3

Build: `2026090242`

## Added

- Persistent implementation tasks generated from BMS audit gaps.
- Task owner restricted to members of the selected company.
- Planned, in-progress, review, completed and cancelled workflow states.
- Start date, due date, expected result, actual result and completion timestamp.
- Supporting evidence files for every task.
- Company/audit task register with status, owner and overdue filters.
- Immutable snapshots of criterion, actual score, target score, gap, BMS tool and Moodle course.

## Upgrade

Install the full ZIP over the current plugin. Do not uninstall it. Moodle adds `local_kbacorp_impl_task` and upgrades to build `2026090242`.
