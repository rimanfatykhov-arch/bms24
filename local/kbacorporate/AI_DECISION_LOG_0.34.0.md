# AI Decision Log v0.34.0

## Stable criterion code is the comparison key

Внутренний ID критерия не используется для исторического сопоставления, потому что новая версия BMS-инструмента может создавать новый набор записей. Сравнение выполняется по immutable snapshot field `criterioncode`.

## Different scoring scales are normalised

Если аудиты используют разные максимумы шкалы, изменение считается по проценту от шкалы. Сырые баллы показываются отдельно, но прямой raw delta формируется только при одинаковой шкале.

## Only confirmed audits are comparable

Черновики и аудиты на проверке могут изменяться. В аналитическую историю допускаются только подтверждённые снимки.

## Evidence does not prove causation

Выполненные действия и принятые доказательства показываются рядом с изменениями критериев, но не маркируются как доказанная причина роста или падения.

## Economic comparison is audit-linked

В `v0.34.0` экономические значения сравниваются только когда они прямо связаны с выбранными аудитами. Автоматический подбор ближайшего периода отложен, чтобы избежать скрытой методологической подстановки.

## Direction-aware interpretation

Для `up` рост считается положительным, для `down` — снижение. Для `target` без отдельной цели результат нейтрален. Денежные значения разных валют не сопоставляются.

## Read-only release

Релиз не добавляет write operations и не изменяет схему. Это снижает риск при пилотной проверке поверх новой economic registry ветки.
