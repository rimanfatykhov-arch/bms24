# Security and Privacy v0.34.1

- Login is required.
- Viewing requires `local/kbacorporate:vieweconomicindicators`.
- Company access is checked before any economic values are read.
- An audit passed in the URL must belong to the selected company.
- Editing links require `manageeconomicindicators`.
- CSV export repeats the same capability and company checks.
- The release adds no personal-data table and no new file area.
- The page is read-only and does not write tracking data.
- Monetary values of different currencies are not merged or compared.
