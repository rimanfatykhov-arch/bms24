# KBA Corporate Dashboard v0.34.0.2

## Исправление регистрации права внедрения BMS

Hotfix исправляет остановку обновления Moodle с сообщением:

`Capability 'local/kbacorporate:managecompanyimplementation' was not found!`

## Причина

В v0.34.0.1 новое право было объявлено в `db/access.php`, но назначалось пользовательской роли непосредственно внутри `db/upgrade.php`. Moodle обновляет таблицу capability-определений компонента после завершения callback обновления плагина, поэтому в момент вызова `assign_capability()` новое право ещё отсутствовало в базе.

## Исправление

- шаг `2026090902` больше не назначает новое право до его регистрации;
- добавлен восстанавливающий шаг `2026090903`;
- перед назначением роли выполняется идемпотентная регистрация capability-определений компонента;
- назначение выполняется только для реально зарегистрированных прав;
- повторный запуск после прерванного обновления безопасен;
- схема бизнес-данных не меняется.

## Обновление после ошибки

Установите полный ZIP v0.34.0.2 поверх файлов v0.34.0.1 и снова запустите обновление Moodle. Ручное изменение таблиц базы данных не требуется.

## Ожидаемый результат

- обновление проходит savepoint `2026090903`;
- право `local/kbacorporate:managecompanyimplementation` зарегистрировано;
- роль `kbacorporatemanager` получает права клиентского внедрения и экономических показателей;
- карточка «Внедрение BMS» становится доступна менеджеру назначенной компании;
- глобальная методология других компаний остаётся закрытой.
