# KBA Corporate Dashboard 0.25.1

This release gives each assigned implementation curator one workspace for all students, tasks and discussions.

- Student/task feed across every programme assigned to the current curator.
- Company context, recent message preview, unread badge and last activity time.
- Search by student, company or task and filter by task status.
- Direct task links and scoped curator access without cross-company leakage.
- Read-state tracking and summary cards for students, tasks, unread messages and overdue tasks.

After installation, complete the Moodle database upgrade and purge caches.
