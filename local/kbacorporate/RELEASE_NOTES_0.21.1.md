# KBA Corporate Dashboard 0.21.1

Build: `2026090240`  
Public API: `1.16` (unchanged)

## Result

The workbook `BMS-CRS-OWN-MBS-001-WBK-A0 — Point A` is now represented as a native, company-scoped Moodle audit template.

## Included

- One-click template installation from the BMS tool library.
- 15 areas and 137 criteria extracted from the workbook without example answers.
- Native 0–9 score scale and endpoint descriptions for every criterion.
- `Needs data` and `Not applicable` states.
- Area-level averages, completion counts and below-7 attention counts.
- Overall BMS Index normalised to 0–100 from equally weighted assessed-area averages.
- Snapshot fields protect historical audits when the template is later changed.

## Compatibility

Existing v0.21.0 tools and audits remain on their 0–5 verified-evidence calculation. No employee competency levels, business-role targets or ERP API methods are changed.

## Deferred

The workbook's free-form `Owner role` time-allocation sheet is not converted in this release. It remains a related learning assignment and is planned as a dedicated structured audit block.
