# KBA Corporate Dashboard 0.18.5

Build: `2026090220`

- The plan page shows overall progress, completed actions, actions in progress and overdue actions.
- Actions due within the next 14 days are included in the progress summary.
- Overdue deadlines are highlighted in the action table.
- The company plan list shows both a progress bar and the overdue-action count.
- Completed actions never count as overdue.

This release has no database schema changes and upgrades directly from 0.18.4.1.
