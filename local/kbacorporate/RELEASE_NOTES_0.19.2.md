# KBA Corporate Dashboard 0.19.2

Build: `2026090227`

- The effectiveness page now groups the filtered IPR result by business role and department.
- Each group reports plan counts, active/completed plans, action completion, overdue actions, confirmed improvements and targets reached.
- Employees without a current role or department remain visible in explicit fallback groups.
- Both group tables are included in CSV exports.
- A multi-role employee contributes to each assigned role; the interface explains that role totals are analytical projections.

This release has no database schema changes and upgrades directly from 0.19.1.
