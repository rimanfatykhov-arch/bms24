# KBA Corporate Dashboard 0.19.1

Build: `2026090226`

- Development effectiveness can be filtered by department and plan status.
- Search matches employee name, email and plan title.
- Summary metrics and table rows always use the same filtered plan set.
- Authorised users can download the current result as semicolon-delimited CSV.
- CSV text is protected against spreadsheet formula injection.

This release has no database schema changes and upgrades directly from 0.19.0 or earlier 0.18.x builds.
