# KBA Corporate Dashboard 0.26.1

This release adds verifiable results to the BMS implementation-task lifecycle.

- The assigned employee describes the completed result before submitting the task for review.
- An optional external result link and up to ten supporting files may be attached.
- The task enters “In review” only after the result has been saved.
- The result and supporting documents are visible to the employee, curator and authorised manager.
- Existing status history, discussion and Moodle notifications remain available on the same task page.

After installation, complete the Moodle database upgrade and purge all caches.

Recommended acceptance path: open an in-progress task as its employee, submit a description, link and file, then open the same task as its curator and verify every result element before accepting or returning it.
