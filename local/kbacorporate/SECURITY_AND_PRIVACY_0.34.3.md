# Security and Privacy 0.34.3

- Панели работают только после `require_login()`.
- Панели компании используют существующую проверку полного доступа к компании.
- Портфель куратора ограничен назначениями пользователя в программах внедрения; административный доступ использует существующую capability.
- Данные агрегируются на сервере и экранируются Moodle API (`format_string`, `s`, `html_writer`).
- Endpoint не принимает команды изменения данных и не выполняет записи.
- Новые персональные данные не сохраняются; схема базы данных не меняется.
- Панель HR показывает агрегаты, а не автоматически рассчитанные новые уровни компетенций.
