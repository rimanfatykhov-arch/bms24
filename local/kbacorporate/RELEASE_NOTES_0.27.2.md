# KBA Corporate Dashboard 0.27.2

This release introduces the structured BMS tool library and full editor for company-owned tools.

- Browse global templates and company tools in one searchable card catalogue.
- Filter by management area, scope and active state.
- See scale, active criteria, sections and current-company audit usage.
- Edit tool identity, management area, description, scale, attention threshold and BMS Index method.
- Edit criterion section, maturity descriptions, evidence guidance, target, weight, order and status.
- Protect global templates from company-context changes and lock a tool code after its first audit.
- Start a new audit from a tool card with that tool already selected.

Build: `2026090280`.

After installation, complete the Moodle upgrade and purge all caches. Open “BMS tool library”, inspect Point A, edit a company criterion, and create an audit directly from the tool page.
