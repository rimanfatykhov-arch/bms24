# KBA Corporate Dashboard 0.26.3

This release adds a visual implementation-task board for curators and administrators.

- The board groups tasks into five controlled workflow stages.
- Every card shows its company, employee, priority, deadline, overdue state and unread-message count.
- Curators see programs assigned to them; authorised administrators may see all assigned programs.
- Search can match task, company or employee; administrators can also filter by company and curator.
- Cards open the existing task workspace for discussion, evidence and controlled status actions.
- Responsive wrapping avoids page-level horizontal scrolling.

After installation, complete the Moodle database upgrade and purge all caches.

Recommended acceptance path: open “Curator students”, choose “Task board”, test search and filters, verify all five columns, and open cards for tasks in planned, review and overdue states.
