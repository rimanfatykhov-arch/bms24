# KBA Corporate Dashboard 0.16.9 — Course filter, search, and collapse view

## Added
- Course filter on the “My Competencies” page.
- Search field for competency title, code, and description.
- Collapse/expand actions for competency cards, including global collapse all / expand all.

## Changed
- Status filter now preserves the selected course and search query.

## Compatibility
- Moodle 4.0+
- No database changes
