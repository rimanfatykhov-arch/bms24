# CHANGELOG — v0.33.0

## Added

- `implementation_actions.php` — предпросмотр и выборочное создание действий из подтверждённых разрывов аудита.
- `classes/local/implementation_actions.php` — расчёт, валидация, сроки и идемпотентное создание.
- Прямые ссылки «Создать действие» / «Открыть действие» в подтверждённом аудите.
- Кнопка «Действия по результатам аудита» в карточке аудита и плане внедрения.
- Сводка покрытия разрывов действиями.
- PHPUnit regression source `tests/implementation_actions_test.php`.

## Changed

- Список допустимых ответственных теперь совпадает с серверной проверкой `isemployee = 1`.
- Сроки новых действий вычисляются из приоритета: 30 / 60 / 90 дней.
- При нескольких маршрутах пользователь выбирает маршрут до создания.

## Governance

- Действия формируются только из подтверждённого аудита и активной программы внедрения.
- Неизвестный уровень не считается нулём.
- Повторный запуск не создаёт дубликаты и не перезаписывает существующие задачи.
- Схема базы данных не изменена.
