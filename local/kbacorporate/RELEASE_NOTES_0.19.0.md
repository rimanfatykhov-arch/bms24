# KBA Corporate Dashboard 0.19.0

Build: `2026090225`

- A new “Development effectiveness” page aggregates individual development plans at company level.
- It shows active/completed plans, action completion, overdue actions and follow-up audit coverage.
- Confirmed outcome indicators include level improvements and role targets reached.
- Corporate managers see the whole permitted company; department managers see only employees in their existing scope.
- Course completion remains separate from confirmed competency growth.

This release has no database schema changes and upgrades directly from 0.18.9 or earlier 0.18.x builds.
