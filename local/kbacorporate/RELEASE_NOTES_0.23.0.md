# KBA Corporate Dashboard 0.23.0

Build: `2026090253`

This release introduces a dedicated customer workspace named “BMS implementation”. It combines the complete implementation journey without duplicating domain data: Point A audit, BMS Index, package selection and commercial request, managed plan and tasks, then Point B and result measurement.

The corporate dashboard implementation card now opens the workspace. Existing audit, assessment, economics, plan and task pages include return navigation. Before a request, editable packages are displayed as customer-facing cards with description, service contents, price and duration.

Upgrade over v0.22.2.2 without uninstalling the plugin. No schema migration is required.
