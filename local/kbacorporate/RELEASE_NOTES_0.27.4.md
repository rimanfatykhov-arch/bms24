# KBA Corporate Dashboard 0.27.4

This release replaces the scattered BMS implementation links with a single workspace menu.

- The menu contains Clients or Client overview, Audits, BMS tools, Students, Task board and Effectiveness.
- The current section is highlighted in green.
- Company-specific options appear only inside a validated company context.
- Switch company and Corporate dashboard are visually separated from daily workspace sections.
- The same navigation is shown on the main implementation screens.
- On mobile devices the primary menu scrolls horizontally without creating page-level overflow.

Build: `2026090282`.

After installation, complete the Moodle upgrade and purge all caches. Open “BMS implementation”, switch between each menu section, select a company, and verify that Audits, BMS tools, Switch company and Corporate dashboard preserve the correct company context.
