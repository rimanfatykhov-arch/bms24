# KBA Corporate Dashboard 0.22.0

Build: `2026090248`

This release separates free BMS audit results from the paid managed implementation service. A company sends a request from the implementation-plan page. A KBA administrator configures the package, commercial state and Bitrix24 deal, then activates the program. Detailed gaps and tasks become available only to a paid active, paused or completed program; task editing is limited to active delivery.

Packages: BMS Start, BMS Support and BMS Transformation.

Upgrade: install the full ZIP over the existing plugin without uninstalling it, then complete Moodle database upgrade. Existing audits and tasks are preserved.
