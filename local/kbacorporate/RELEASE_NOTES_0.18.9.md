# KBA Corporate Dashboard 0.18.9

Build: `2026090224`

- Completed IPRs show the competency level captured before development and the current confirmed level.
- Summary metrics show assessment coverage, improved levels, reached targets and remaining confirmed gaps.
- Newly assessed competencies are distinguished internally from confirmed level growth.
- Unassessed competencies remain “Not assessed”; they are never interpreted as level zero.
- Course completion does not affect the measured outcome until an audit confirms the competency level in Moodle.

This release has no database schema changes and upgrades directly from 0.18.8 or earlier 0.18.x builds.
