# KBA Corporate Dashboard 0.18.8

Build: `2026090223`

- A completed IPR offers creation of a focused follow-up competency audit.
- The audit contains only competencies developed through that plan.
- Existing Moodle levels, evidence and corporate course competency results are collected automatically.
- One plan links to one audit; repeated use opens the same audit.
- Audit confirmation remains the only operation that can update the authoritative Moodle competency level.

This release adds `followupauditid` to development plans and upgrades directly from 0.18.7 or earlier 0.18.x builds.
