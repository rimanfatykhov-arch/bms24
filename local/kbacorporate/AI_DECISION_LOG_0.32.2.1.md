# AI Decision Log — v0.32.2.1

## Симптом

Переход по ссылке `templatecompetencies.php?templateid=4` завершался ошибкой Moodle:

```text
Отсутствует обязательный параметр (pagecontextid)
Error code: missingparam
```

## Root cause

KBA helper `moodle_learning_plans::template_url()` передавал только `templateid`, тогда как стандартная страница Moodle требует также `pagecontextid`.

## Рассмотренные варианты

1. Жёстко добавить `pagecontextid=1`.
   - отклонено: системный context ID обычно равен 1, но контракт не должен зависеть от жёсткого значения;
2. Всегда передавать context из вызывающей страницы.
   - рабочий вариант, но оставляет helper небезопасным для будущих вызовов;
3. Определять контекст внутри helper по записи шаблона и разрешить явное переопределение.
   - принято.

## Решение

`template_url(templateid, pagecontextid = 0)`:

- использует переданный контекст, если он задан;
- иначе читает `competency_template.contextid`;
- если запись не дала контекст, использует системный context как fallback;
- формирует URL с обоими обязательными параметрами.

## Ограничения

Helper формирует URL, но не заменяет проверки прав Moodle. Доступ к шаблону по-прежнему проверяет стандартный `tool_lp`.
