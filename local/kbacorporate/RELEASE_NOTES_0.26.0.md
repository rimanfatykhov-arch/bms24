# KBA Corporate Dashboard 0.26.0

This release closes the operational task loop for BMS implementation.

- The employee opens “My BMS tasks”, accepts a planned task and submits it for review.
- The curator or authorised manager accepts the result or returns it for revision.
- Status changes, authors, timestamps and decision comments remain visible in the task history.
- Participants receive Moodle bell/email notifications with a direct task link.
- Deadlines and overdue tasks are visible in the personal task queue.

After installation, complete the Moodle database upgrade and purge all caches.

Recommended acceptance path: assign an employee to a planned task, log in as that employee, run the task through “Start work” and “Submit for review”, then log in as the curator and test both review decisions.
