## Runtime-проверка после установки

### Preconditions

- включён стандартный механизм компетенций Moodle;
- у менеджера есть права KBA на управление планами развития и применимые Moodle capabilities;
- сотрудник входит в компанию;
- сотруднику назначена бизнес-роль с конкретными компетенциями;
- есть хотя бы один подтверждённый положительный разрыв;
- KBA-план отсутствует либо находится в статусе «Черновик».

### Test case 1 — финальная проверка

1. Открыть «Конструктор учебного плана по разрывам компетенций».
2. Выбрать одну или несколько компетенций.
3. Нажать «Перейти к созданию учебного плана».
4. Проверить карточки, действия и таблицу состава.
5. Убедиться, что неоценённые компетенции не попали в состав.
6. Убедиться, что обязательные компетенции без курса отмечены предупреждением.

Ожидаемый результат: данные не изменены; показан финальный состав и обязательное подтверждение.

### Test case 2 — создание

1. Установить флажок подтверждения.
2. Нажать «Создать / обновить учебный план».
3. Открыть план KBA.
4. Открыть стандартный учебный план Moodle.

Ожидаемый результат:

- создан один KBA-план либо обновлён существующий черновик;
- создан один Moodle-план либо восстановлена/обновлена существующая связь;
- владелец Moodle-плана совпадает с сотрудником;
- состав компетенций совпадает;
- итоговый экран показывает успешную проверку.

### Test case 3 — повторный запуск

Повторить тот же сценарий с тем же составом.

Ожидаемый результат:

- новый KBA-план не создаётся;
- новый Moodle-план не создаётся;
- дубли компетенций не появляются;
- строки показываются как «без изменений» либо синхронизируются идемпотентно.

### Test case 4 — частичная ошибка Moodle

Выполнить под пользователем без применимого Moodle capability либо при отключённом competency subsystem.

Ожидаемый результат: KBA-данные не теряются; пользователь получает предупреждение и может повторить синхронизацию после устранения причины.

## Ограничение теста

Фактическое выполнение PHPUnit и runtime-проверка `core_competency\api` выполняются непосредственно на Moodle 4.0 пилотного сервера.
