Файл: `tests/study_plan_progress_test.php`.

Проверяется:

1. неоценённый уровень не превращается в 0;
2. корректно считаются выполнение действий, достижение целей и покрытие оценкой;

5. фильтры не изменяют исходный набор строк;
6. поиск работает по компетенции, коду и курсу.

## Runtime-проверка после установки

### Preconditions

- есть сотрудник с созданным планом KBA;
- план содержит хотя бы один пункт с курсом;
- сотрудник зачислен хотя бы на один курс;
- completion tracking настроен хотя бы в одном курсе;
- план находится в статусе «Активен» либо «Завершён».

### Test case 1 — открытие прогресса

1. Открыть карточку плана KBA.
2. Нажать «Прогресс учебного плана».
3. Проверить карточки показателей и таблицу.

Ожидаемый результат: отображаются текущие статусы действий, курсов, сроков и подтверждённых уровней.

### Test case 2 — курс не начат / в процессе

1. Открыть курс сотрудника и выполнить часть активностей.
2. Вернуться на страницу прогресса.

Ожидаемый результат: статус курса меняется на «Проходит курс», прогресс отображается в процентах, уровень компетенции не меняется автоматически.

### Test case 3 — завершение курса

1. Завершить курс согласно Moodle completion.
2. Нажать «Синхронизировать завершение курсов».

Ожидаемый результат: соответствующее действие плана становится завершённым; повторный запуск не создаёт изменений и дублей.

### Test case 4 — повторная оценка

1. Завершить все действия плана.
2. Убедиться, что план получил статус «Завершён».
3. Нажать «Создать повторную оценку компетенций».

Ожидаемый результат: создаётся один аудит типа development либо открывается уже существующий; состав ограничен компетенциями плана.

### Test case 5 — права доступа

1. Открыть страницу как сотрудник-владелец плана.
2. Открыть как менеджер с доступом к сотруднику.
3. Открыть как пользователь без доступа.

Ожидаемый результат: владелец и уполномоченный менеджер видят прогресс; посторонний пользователь получает отказ; действия синхронизации и создания оценки доступны только при соответствующих правах.

## Ограничение теста

Фактическое выполнение PHPUnit, completion API и runtime-проверка выполняются непосредственно на пилотном Moodle 4.0.
