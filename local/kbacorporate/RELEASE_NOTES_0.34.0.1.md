# KBA Corporate Dashboard v0.34.0.1
## Доступ клиента к внедрению BMS

**Build:** `2026090902`  
**Status:** BETA / pilot hotfix  
**Upgrade from:** `v0.34.0`

## Исправленная проблема

Корпоративный руководитель новой компании видел корпоративный кабинет, но карточка **«Внедрение BMS»** не отображалась. Клиентские страницы внедрения использовали то же право, что и глобальное администрирование методологии BMS. Это право намеренно не выдавалось корпоративной роли, чтобы не открывать Framework Manager, глобальную библиотеку инструментов и JSON-администрирование.

## Решение

Добавлено отдельное право:

`local/kbacorporate:managecompanyimplementation`

Оно разрешает работу с внедрением только при наличии полной управленческой принадлежности к конкретной компании.

Корпоративный руководитель теперь может в своей компании:

- видеть карточку и постоянную ссылку **«Внедрение BMS»**;
- открывать реестр аудитов и создавать аудит;
- заполнять и подтверждать аудит;
- оформлять заявку и просматривать план внедрения;
- создавать и редактировать действия/задачи внедрения;
- работать с доказательствами и проверкой результата;
- просматривать прогресс по разделам и сравнение аудитов;
- просматривать и вести экономические показатели своей компании.

При этом по-прежнему недоступны глобальные административные разделы:

- Framework Manager;
- глобальная библиотека инструментов BMS;
- JSON import/export методологии;
- глобальные маршруты и критерии;
- межклиентский Канбан и аналитика портфеля, если пользователь не является куратором или BMS-администратором.

## Безопасность

Наличие права само по себе недостаточно. Каждый запрос дополнительно проверяет, что пользователь является полным корпоративным руководителем выбранной компании. Передача `companyid` другой компании блокируется.

Файлы доказательств, задачи, аудиты и экономические данные используют ту же проверку компании.

## Совместимость

- Схема базы данных не меняется.
- Существующие аудиты, задачи, доказательства и экономические значения не изменяются.
- При обновлении новое право автоматически назначается созданной плагином роли `kbacorporatemanager`.
- Также этой роли назначаются уже существующие права просмотра и управления экономическими показателями.

## Проверка после установки

1. Очистить кэши Moodle, если карточка не появилась сразу.
2. Войти под корпоративным руководителем новой компании.
3. Открыть `/local/kbacorporate/index.php?companyid=<ID>`.
4. Убедиться, что видна карточка **«Внедрение BMS»**.
5. Открыть её и создать тестовый аудит.
6. Попытаться открыть `Framework Manager` прямой ссылкой — доступ должен быть запрещён.
7. Попытаться подставить `companyid` другой компании — доступ должен быть запрещён.
