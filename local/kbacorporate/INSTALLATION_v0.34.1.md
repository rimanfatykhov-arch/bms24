# Installation v0.34.1

1. Back up the database and `local/kbacorporate`.
2. Install the ZIP through Moodle plugin administration or replace the plugin directory.
3. Complete the Moodle upgrade to build `2026090904`.
4. Purge all caches.
5. Open `/local/kbacorporate/economic_dashboard.php?companyid=<ID>`.

No database tables or fields are added. The economic registry from `v0.33.4` is required.
