# Development Log — 2026-09-02 — v0.17.3

Implemented the first automated competency-audit workflow:

- one-click audit creation from the employee target profile;
- immutable role requirement snapshot per audit item;
- automatic collection of current Moodle level, core competency evidence and company-course competency results;
- separate missing/pending/confirmed/rejected states;
- manual assessor input only for unresolved items;
- bulk confirmation through core Moodle grading;
- structured evidence export and child-first deletion.

Local environment lacks PHP and a Moodle database. Therefore XML, language parity, PHP structure, archive integrity and static consistency are checked locally; PHP lint, PHPUnit, upgrade and acceptance remain target-server gates.
