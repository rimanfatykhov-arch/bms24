# KBA Corporate Dashboard 0.17.2 — Competency Audit

- Build: `2026090103`
- Public API: `1.15` (unchanged)
- Upgrade: additive from `2026090102`; do not uninstall

This release adds company-scoped employee audit sessions and preliminary competency assessments. Self, test, interview, practice, expert and AI results remain pending until explicit review. Confirmation calls Moodle core Competency API and becomes the authoritative employee level; rejection never changes that level.

Learning Plans remain optional. The competency framework supplies competency identity and scale; the business-role profile supplies the target level; the audit supplies evidence of the current level.

Full-company scope, Moodle core grading capability, Privacy API coverage and safe member/company lifecycle deletion are mandatory boundaries.
