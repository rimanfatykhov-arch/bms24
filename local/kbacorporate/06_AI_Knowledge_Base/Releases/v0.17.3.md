# KBA Corporate Dashboard 0.17.3 — Automated Role-based Audit

Build: `2026090200`. Public API: `1.15`.

The audit scope is now generated from active business roles inside one explicit company. Each item snapshots its Moodle competency, role target, priority, required flag and contributing roles.

The collector reads:

- authoritative `competency_usercomp.grade`;
- `competency_evidence` belonging to that user competency;
- `competency_usercompcourse` results only for courses assigned to the selected company.

Confirmed current grades are accepted. Other grade-bearing results are preliminary until explicit confirmation through Moodle Competencies API. Missing evidence uses a separate `missing` state and is never interpreted as level 0.

The primary manual Evidence URL field was removed. Structured evidence is stored in `local_kbacorp_audit_ev` as a dated audit snapshot and is covered by lifecycle deletion and Privacy API.

Learning Plans remain optional learning sources and do not define the business-role audit.
