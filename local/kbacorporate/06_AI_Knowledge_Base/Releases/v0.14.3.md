# KBA Corporate Dashboard v0.14.3 — Release Notes

Build: `2026081801`  
Public API: `1.10`  
Target production: Moodle 4.1.22 / PHP 7.4.33

## Purpose

Adds administrator-controlled provisioning of the Bitrix24 Contact field used for corporate learning roles, while preserving the architecture boundary: Corporate Dashboard never stores Bitrix24 credentials and never calls Bitrix24 REST directly.

## New administrator flow

1. Configure **KBA Connect base URL** and optional integration Bearer token.
2. Open **KBA Corporate Dashboard → Bitrix24 corporate roles**.
3. Review the desired schema.
4. Click **Create / check Bitrix24 field**.
5. Dashboard sends the declarative schema to KBA Connect:
   - `GET /corporate/schema/status`
   - `POST /corporate/schema/provision`
6. KBA Connect is responsible for checking/creating/updating the Bitrix24 Contact user field.

## Required Bitrix24 role field

- Entity: Contact
- Type: enumeration/list
- Multiple: yes
- Stable role XML_ID values:
  - `employee`
  - `corporate_manager`
  - `department_manager`
  - `hr`

## Safety

- No Bitrix24 webhook/token is stored by this plugin.
- No automatic field deletion is implemented.
- Provisioning is expected to be idempotent in KBA Connect.
- If KBA Connect endpoints are unavailable, Dashboard reports the condition and continues to operate normally.

## Database

No XMLDB schema changes in v0.14.3. Upgrade contains a standard savepoint only.
