# People & Competency Architecture

## Core chain

Company
→ Org Unit
→ Position
→ Business Role / Functions
→ Competency Requirements
→ Employee
→ Assessment
→ GAP
→ Development Plan
→ Learning
→ Reassessment

## Principles

A position defines requirements.
An employee has evidence/assessment against those requirements.

Do not store a competency gap as an arbitrary independent truth if it can be derived from:
required level vs assessed/current level.

## Learning linkage

Learning is execution in Moodle/KBA Corporate.
BMS owns:
- management requirement
- development need
- development plan
- linkage to learning
- management evidence/decision

Moodle owns:
- enrolment
- content delivery
- completion
- grade
- certificate

## Future ERP sync

Design identities and mappings so the same employee/position/competency model can later synchronize with Odoo without replacing canonical BMS identities.
