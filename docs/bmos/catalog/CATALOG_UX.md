# CAT-0. Пользовательский опыт каталога

**Статус: PROPOSED.** Экранов в продукте нет. [Статический прототип](prototype/index.html) — один HTML-файл на
синтетических данных, без сети, без JavaScript-вызовов к серверу, кнопки активации отключены. Будущая реализация —
в собственной оболочке BMS24 (`bms24_*`, `.bms24-app`, цвета BMOS), по стандартам UI/CRUD.

## 1. Роли пользователей

| Роль | Что делает в каталоге |
|---|---|
| Руководитель / владелец компании | Смотрит, какие роли можно поручить цифровому исполнителю; сравнивает статусы; запускает мастер подготовки |
| Методолог / HR | Сопоставляет Role DNA шаблона с функциями поста, проверяет Recognition |
| Администратор BMOS компании | Выбирает профиль модели, лимиты, проверяет инструменты |
| Владелец методологии (BMS) | Публикует редакции шаблонов через PR (вне UI в CAT-1/CAT-2) |

## 2. Экран «Каталог»

- Карточки шаблонов: код, название, категория, статус зрелости, минимальный этап BMOS, краткое назначение.
- Фильтры: категория, статус, этап BMOS, риск-классы, «можно адаптировать сейчас».
- Поиск по названию и коду.
- Статус показывается словом и цветом (не только цветом): CONCEPT — серый, DESIGNED — синий, VALIDATED — изумрудный,
  COMPATIBLE — тёмно-синий, DEPRECATED — песочный с зачёркнутой меткой.
- Пустое состояние и состояние «каталог выключен» (Q-02) — с понятным текстом.

## 3. Карточка шаблона (вкладки)

| Вкладка | Содержание |
|---|---|
| ЦКП и функции | ЦКП, Р1…Рn с критериями; какие функции поста покрывает; что остаётся за человеком |
| Компетенции | Проект Role DNA: знания, навыки, решения, ограничения; ссылки на рамки компетенций |
| AI Execution Profile | 11 блоков AEP: требования к модели (возможности), контексту, памяти, выходу, надзору |
| Инструменты и зависимости | Команды A0_04 с риск-классом, scope и этапом; модули и версии; признак «доступно на текущей версии» |
| Полномочия и риски | Запрашиваемые гранты (как запрос), разрешённые и исключённые классы риска, ограничения пилота |
| Recognition | Кейсы и negative cases, статус прогона (NOT RUN, пока не прогнаны), критерии допуска |
| Версии | Редакции, статусы, change log, digest, совместимость с версиями платформы |

На карточке нет кнопок, которые выдают права или запускают агента. Единственное действие — «Подготовить агента»
(мастер), доступное, только если шаблон опубликован, не `DEPRECATED` и этап BMOS достаточен.

## 4. Мастер подготовки

- 12 шагов из [CATALOG_LIFECYCLE §3](CATALOG_LIFECYCLE.md); индикатор прогресса; черновик сохраняется на каждом шаге.
- На каждом шаге — плашка «Этот шаг не выдаёт прав и не запускает агента» (кроме шага 10, где явно перечисляются
  выдаваемые гранты, и шага 12).
- Шаги, недоступные на текущем этапе BMOS, показаны заблокированными с причиной («Доступно с A3»).
- Клавиатурная навигация, видимый фокус, RU/EN тексты, адаптивные таблицы.

## 5. Прототип

`prototype/index.html`: каталог из 12 карточек (AGENT-001 — DESIGNED, остальные CONCEPT), фильтр по статусу и
категории (локально в странице), карточка AGENT-001 с вкладками и экран мастера. Все данные синтетические; кнопки
«Активировать», «Выдать права», «Запустить» имеют атрибут `disabled` и подпись «Недоступно в CAT-0».
