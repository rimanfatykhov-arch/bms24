# CAT-0. Безопасность каталога

**Статус: PROPOSED.** Дополняет A0_07 (PR #183, ревизия 5 (`204e12e`)) и не ослабляет его. Каталог не участвует в проверке прав
Gateway: ни одно правило ниже не создаёт исключений из 15 шагов A0_03.

## 1. Инварианты

| № | Инвариант | Как обеспечивается (проект) |
|---|---|---|
| CS-01 | Ядро Moodle не меняется | Только плагины `local_*`; изменений core нет |
| CS-02 | Второго движка провайдеров нет | Модели — только через `local_kbaai` (A0_05); шаблон требует возможности, а не провайдера |
| CS-03 | Агент не пользователь Moodle | Шаблон и экземпляр не создают `user`; идентичность — `WorkPrincipal` (A0_02) |
| CS-04 | Нет имперсонации спонсора | `userid` спонсора не используется как исполнитель; действия записываются от принципала (A0_07) |
| CS-05 | Человеческий контур неизменен | Каталог и мастер не пишут в `posassign`, `poscover`, `task.assigneeid`, `dutypositionuuid` и историю людей |
| CS-06 | Нет секретов в шаблонах | Ключи, токены, `credentialref` запрещены в пакете; проверка пакета отклоняет такие поля (CAT-1) |
| CS-07 | Нет клиентских данных в шаблонах | Примеры и кейсы — только синтетика; запрещены UUID компаний, людей, постов, Moodle user ID, реальные имена |
| CS-08 | Runtime не делает прямых HTTP, SQL, произвольного исполнения | Инструменты шаблона — только команды A0_04 через Gateway (A0_12) |
| CS-09 | Шаблон не выдаёт права | `grant_requirements` — запрос; гранты выдаёт человек отдельно (мастер, шаг 10) |
| CS-10 | Шаблон не запускает агента | Ни публикация, ни адаптация, ни статус `VALIDATED/COMPATIBLE` не создают запуск; запуск — только ручной, после всех ворот |
| CS-11 | Адаптация только сужает | CATALOG_TEMPLATE_CONTRACT §4 |
| CS-12 | Обновление шаблона не меняет экземпляры | CATALOG_LIFECYCLE §2 |
| CS-13 | Реальные модели — только по отдельному разрешению | Пилот на mock / синтетике; подключение реальных ключей (в т. ч. Timeweb) — отдельное решение владельца |
| CS-14 | Нет DDL и runtime каталога до архитектурного согласования | CAT-0 — только документы; CAT-1+ — после A0 PASS и OD-01/OD-02 |
| CS-15 | Assessor и BMS Assistant не затрагиваются | `bms_profile_registry` не меняется; шаблоны не регистрируются как операции ассистента |

## 2. Угрозы

| № | Угроза | Мера |
|---|---|---|
| CT-01 | В пакет попали секреты или данные клиента | CS-06/CS-07; ревью PR пакета; автоматическая проверка запрещённых полей и шаблонов значений (CAT-1) |
| CT-02 | Подмена пакета между ревью и импортом | `package_digest` (SHA-256 канонического пакета); импорт сверяет digest с опубликованной редакцией; подпись — OD-02 |
| CT-03 | Автоматическая выдача прав из шаблона | CS-09; мастер не имеет кода выдачи грантов, шаг 10 вызывает обычный сервис грантов A0_02 с проверкой прав человека |
| CT-04 | Расширение полномочий через адаптацию | CS-11; проверка `tools ⊆ required_tools`, `risk ⊆ risk_classes`, scope не шире шаблона |
| CT-05 | Расширение через новую редакцию шаблона без ведома компании | CS-12; переход экземпляра — решение человека с анализом влияния и повторной проверкой |
| CT-06 | Утечка между компаниями через глобальный каталог | Каталог не хранит компанейских данных; провенанс хранится только в экземпляре; каталог не знает, кто его адаптировал |
| CT-07 | Утечка через «примеры» в Recognition Pack | Только синтетика; результаты проверок — в компанейском контуре по ACL (OWNERSHIP §1) |
| CT-08 | Зависимость от одного поставщика | CS-02; `model_requirements` — возможности; профиль выбирает администратор компании |
| CT-09 | Вмешательство в Assessor/Assistant | CS-15 |
| CT-10 | Ложное доверие к статусу | `VALIDATED`/`COMPATIBLE` — свидетельства для конкретной редакции и версии платформы, не разрешения; UI показывает их вместе с ограничениями |
| CT-11 | Шаблон требует команд будущего этапа | `min_bmos_stage` и этапы команд A0_04; адаптация до нужного этапа запрещена (мастер, шаг 5) |
| CT-12 | Использование отозванной редакции | `withdrawn`/`DEPRECATED` запрещают новые адаптации; экземпляры получают анализ влияния |

## 3. Что проверяется в CAT-0

Только документально: что перечисленные инварианты записаны и не противоречат A0. Автоматические проверки
пакета, импорта и мастера — NOT RUN (их нет до CAT-1…CAT-4).
