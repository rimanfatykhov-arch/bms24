## Решения

| ID | Вопрос | Решение владельца | Где отражено |
|---|---|---|---|
| Q-01 | Направление ADR-0013 | Утверждено при условии устранения замечаний review | ADR-0013, A0_13 |
| Q-02 | Где разместить Agent Runtime | Отдельный выключаемый плагин `local_bmosruntime`. Изоляция модульная, а не физическая | A0_01 §4, A0_12 |
| Q-03 | Внешние агенты | До A4 только внутренний Runtime; внешние агенты — отдельным ADR | A0_04 §2, A0_12 §2 |
| Q-04 | Профили моделей | Версионный реестр моделей в `local_kbaai`; второго provider engine нет | A0_05 §3 |
| Q-05 | Секреты | Защищённая серверная конфигурация вне Git, затем vault; в БД только алиас и отпечаток | A0_02 §5 |
| Q-06 | Ключи Timeweb | Отдельный ключ на компанию + квоты BMS | A0_02 §5, A0_06 §6 |
| Q-07 | UUID и ревизии `posassign` | Отдельная задача вне BMOS | A0_01 §7 C1, A0_10 |
| Q-08 | Отчёт агента | Отдельное хранение; общий UI; human `dreport` без миграции | A0_06 §7, A0_10 A2-01 |
| Q-09 | Два лица и сроки | Принцип двух лиц для самостоятельного поста (`mode=agent`) и для R3. Спонсор, который поручил работу, не утверждает собственное R3. Approval — 72 ч. Сначала разрешены только собственный результат и предложения; комментарии — после проверки атрибуции | A0_02 §3, A0_04 §4, A0_07 §3 |
| Q-10 | Срок гранта | Не больше 90 дней, продление — контролируемое (новая ревизия, человек) | A0_02 §4 |
| Q-11 | Отчёты и задачи команды | Только отдельный делегированный scope; права спонсора не используются | A0_02 §4.1 |
| Q-12 | Условия Timeweb | Договор, резидентность и условия обработки проверяются до клиентских данных; сначала только синтетика | A0_05 §4, A0_10 A3 |
| Q-13 | Диагностика с полным промптом | По умолчанию выключена; максимум 7 дней; маскирование, ACL, аудит | A0_06 §3 |
| Q-14 | Kill switch | Срабатывает до следующей защищённой операции или вызова модели; уже идущий вызов (in-flight) обрабатывается отдельно | A0_03 §5, A0_12 §4 |
| Q-15 | Хранение ключей идемпотентности | Не меньше 30 дней и не меньше горизонта повтора; журналы — по политике | A0_04 §8 |
| Q-16 | AI Billing | В A1 — внутренние лимиты и учёт расходов; клиентский биллинг — SaaS/A4 | A0_06 §6 |
| Q-17 | 22 сценария | Сверить с исходным заданием и дополнить | A0_09 §1 |
| Q-18 | ADR-0012 (MAX) | Отдельный совместимый срез A1-12 после приёмки существующего контура MAX, без изменения поведения | A0_10 §2, §3 |
